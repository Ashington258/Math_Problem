# 级数展开

全纯函数局部一定可以展开为幂级数，而在有奇点的圆环上则展开为含负幂的 Laurent 级数。后者是第 7 章奇点分类与留数计算直接的工具。

- [Taylor 与 Laurent 展开](Taylor与Laurent展开.md)：幂级数与收敛半径、Taylor 定理、标准展开表、Laurent 级数与收敛圆环。

核心对照：

$$
\text{Taylor}:\ \sum_{n\ge0}a_n(z-z_0)^{n}
\qquad
\text{Laurent}:\ \sum_{n\in\mathbb Z}a_n(z-z_0)^{n}.
$$
