# 实积分应用

本节是整门课的**核心产出**：把实轴上算不出来的积分搬到一个围道上，用留数定理算出结果。

- [留数法计算实积分](留数法计算实积分.md)：有理函数型、三角有理式型、多值函数型（keyhole 围道）。
- [Jordan 引理与围道设计](Jordan引理与围道设计.md)：Jordan 引理、缩进围道，以及目标例题 $\displaystyle\int_{-\infty}^{\infty}\frac{\cos x}{1+x^{2}}dx=\frac{\pi}{e}$。

三条通用动作：

$$
\text{选围道}\to\text{证补段为 }0\ (\text{ML / Jordan})\to 2\pi i\sum\operatorname{Res}.
$$
