# 复数的几何

本节把复数从“数”变成“平面上的一点与一个向量”，并顺手建立复分析的通用语言：开集、区域、连通与单连通。

- [复数的几何表示](复数的几何表示.md)：共轭、模与辐角、Euler 公式、乘法的旋转—伸缩解释，以及扩充复平面与区域语言。

核心图景：加法是向量平移，乘法是**旋转加伸缩**，而 $e^{i\theta}$ 就是纯粹的旋转算子。

$$
(z,w)\mapsto zw:\quad
\text{模相乘、辐角相加}
\quad\Longrightarrow\quad
e^{i\theta}\cdot re^{i\varphi}=re^{i(\theta+\varphi)}.
$$
