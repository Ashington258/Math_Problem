# 复分析

复分析研究复变量函数 $w=f(z)$ 的微分与积分。它的核心张力在于：**一个看似只要求“可微”的条件（全纯性），却强制出了无穷可微、幂级数展开、围道积分与整体几何之间的完整链条**。

本区按“几何 → 局部（全纯）→ 多值性 → 积分 → 整体定理 → 级数 → 奇点 → 留数 → 实积分 → 物理应用”组织。

## 学习路径

1. [复数的几何](00_复数的几何/README.md)：共轭、模与辐角、Euler 公式，以及区域、开集与连通的语言。
2. [复变函数与极限](01_复变函数与极限/README.md)：$w=f(z)$ 作为 $\mathbb R^2\to\mathbb R^2$ 的映射、复数极限与连续性。
3. [全纯性](02_全纯性/README.md)：导数定义、Cauchy–Riemann 方程、调和函数与共轭调和函数。
4. [初等函数与分支](03_初等函数与分支/README.md)：$e^z$、$\sin$、$\cos$、$\log z$、$z^{\alpha}$，支点、支割线与主值。
5. [复积分](04_复积分/README.md)：参数化计算、ML 估计、$\oint z^{n}\,dz$ 与原函数存在性。
6. [柯西定理族](05_柯西定理族/README.md)：Cauchy 定理、积分公式、导数公式、Liouville 定理与最大模原理。
7. [级数展开](06_级数展开/README.md)：Taylor 级数、Laurent 级数与圆环收敛域。
8. [孤立奇点与留数](07_孤立奇点与留数/README.md)：奇点分类、零点与极点的阶、留数速算公式。
9. [留数定理与辐角原理](08_留数定理与辐角原理/README.md)：留数定理、辐角原理、Rouché 定理。
10. [实积分应用](09_实积分应用/README.md)：有理函数、三角有理式、Jordan 引理、缩进围道与 keyhole 围道。
11. [变换与物理](10_变换与物理/README.md)：Bromwich 逆拉普拉斯、逆 Fourier、级数求和与色散关系。

主线依赖关系：

$$
\text{复数几何}
\to \text{映射与极限}
\to \text{全纯性}
\to \text{多值分支}
\to \text{复积分}
\to \text{Cauchy 定理族}
\to \text{级数展开}
\to \text{奇点与留数}
\to \text{实积分与物理}.
$$

## 阶段目标与可压缩项

| 阶段 | 内容 | 必须掌握的输出 | 可压缩/跳过 |
| --- | --- | --- | --- |
| 0. 复数的几何 | 共轭、模辐角、极坐标、Euler 公式、乘法 = 旋转 + 伸缩 | $e^{i\theta}$ 的一切几何直觉；区域、开集、连通的语言 | 复数的形式构造 |
| 1. 复函数与极限 | $w=f(z)$ 作为 $\mathbb R^2\to\mathbb R^2$ 映射、连续性 | 会画 $z^{n}$、$e^{z}$、$\frac1z$ 的映射图像 | 拓扑细节 |
| 2. 全纯性 | 导数定义、Cauchy–Riemann 方程、调和函数、共轭调和 | 判全纯、求调和共轭、理解“全纯 = 无旋无源” | 一切高维推广 |
| 3. 初等函数与分支 | $e^{z}$、$\sin$、$\cos$、$\log z$、$z^{\alpha}$、支点、支割线、主值 | **先切分支再积分**，这是后面所有多值积分的命门 | Riemann 面 |
| 4. 复积分 | 参数化、ML 估计、$\oint z^{n}\,dz$、原函数存在 $\iff$ 路径无关 | 会用 ML 估计证明圆弧段趋于 $0$ | Stieltjes 积分细节 |
| 5. 柯西定理族 | Cauchy 定理（三角形/单连通/形变）→ 积分公式 → 导数公式 → Liouville → 最大值原理 | 会“形变围道”这一手 | 证明可只记 Green 公式版本 |
| 6. 级数展开 | Taylor、Laurent、收敛圆环 | 会展开几个标准函数、判断收敛域 | Weierstrass 定理 |
| 7. 孤立奇点分类 | 可去/极点/本质、零点与极点的阶数、留数计算 | **三种留数速算公式必须条件反射** | 本质奇点的深理论 |
| 8. 留数定理 | 留数定理、辐角原理、Rouché 定理 | 会用；辐角原理直接接 Nyquist 判据 | 应用形式的详细证明 |
| 9. 实积分应用 | 有理函数积分、三角有理式、Jordan 引理、缩进围道、$\int x^{a-1}/(1+x)$ 型、keyhole 围道 | **能独立算出** $\displaystyle\int_{-\infty}^{\infty}\frac{\cos x}{1+x^{2}}\,dx=\frac{\pi}{e}$ | 特殊围道的收藏 |
| 10. 变换与物理 | Bromwich 逆拉普拉斯、逆 Fourier、级数求和、Green 函数、Kramers–Kronig | 逆变换由留数给出；**极点 = 模态，留数 = 强度/耦合系数** | 拓扑荷、QFT 传播子 |

## 记号约定

设 $z=x+iy\in\mathbb C$，其中 $x=\operatorname{Re}z$，$y=\operatorname{Im}z$。

| 对象 | 推荐记号 | 说明 |
| --- | --- | --- |
| 复共轭 | $\overline{z}=x-iy$ | 不用 $z^{*}$，避免与伴随矩阵混淆 |
| 模 | $\lvert z\rvert=\sqrt{x^{2}+y^{2}}$ | 表格内一律写 `\lvert z\rvert` |
| 辐角（多值） | $\operatorname{Arg}z=\arg z+2k\pi$ | $k\in\mathbb Z$ |
| 辐角主值 | $\arg z\in(-\pi,\pi]$ | 支割线取负实轴 |
| 实部算子 | $\operatorname{Re}$、$\operatorname{Im}$ | 不用 $\mathrm{Re}$ |
| 对数主值 | $\operatorname{Log}z=\ln\lvert z\rvert+i\arg z$ | 大写表主值 |
| 围道积分 | $\displaystyle\oint_{\gamma}f(z)\,dz$ | 逆时针为正方向 |
| 留数 | $\operatorname{Res}_{z=z_0}f(z)$ | 一阶极点简写 $\operatorname{Res}_{z_0}f$ |
| 阶数记号 | $O$、$o$ | 与 `01_极限` 篇一致 |
