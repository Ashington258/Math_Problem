# 全纯性

本节是整门课的分水岭：把复导数定义写下来，立刻得到 Cauchy–Riemann 方程；再加一条偏导连续性，就得到“全纯”这一核心概念。全纯函数自动拥有调和实部虚部，几何上则体现为保角。

- [全纯函数与 Cauchy–Riemann 方程](全纯函数与Cauchy-Riemann方程.md)：复导数、CR 方程、全纯判据、调和函数与共轭调和函数、保角性。

一句话概括本节的价值：

$$
\text{全纯}
\iff
\text{满足 CR}
\iff
\text{实部虚部互为共轭调和}
\iff
\text{无旋}\ \text{且}\ \text{无源}.
$$
