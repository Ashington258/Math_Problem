# 差分与求和

本节处理离散分析的下半块：**局部变化** $\Delta$ 与**整体累积** $\sum$ 的关系。

- [数列求和的离散微积分](斯托克斯启发_数列求和的离散.md)：差分与望远镜求和，从等差数列到高阶数列求和的机械通道。

核心恒等式是离散版的牛顿–莱布尼茨公式：

$$
\sum_{k=a}^{b}\Delta F(k)=F(b+1)-F(a),
$$

它把求和问题化为"找原函数 + 取边界差"，与 $\displaystyle\int_a^b f'(x)\,dx=f(b)-f(a)$ 逐字对应。这就是[微积分基本思想](../../01_微积分/06_微积分基本思想/关于微积分基本定理的思考.md)（边界抵消）在离散情形下的副本；本篇的表层是求和技巧，底层是这条定理。

本节目前只覆盖 $\Delta$ 的一元情形。更完整的算子体系——$\Delta=E-I$、$\nabla=I-E^{-1}$、二项式差分 $\Delta^{k}=\sum_j(-1)^{k-j}\binom{k}{j}E^{j}$、Leibniz 法则与 umbral 对应——见 [连续与离散算子对照的总对照表](../02_差分方程与算子法/连续与离散算子对照.md#compare-table) 与各篇的推导要点。

**待补方向**：不定和（antidifference）的一般算法、求和与分数阶差分的连续化（time scale calculus）。
