# 离散分析

离散分析研究定义在整数上的对象：数列、递推、有限差分与求和。它与微积分的关系不是"近似"，而是**结构同构**——把导数换成差分、积分换成求和、微分算子 $D$ 换成移位算子 $E$，几乎所有结论都能逐条平移，只有系数的位置发生可预测的漂移。

本区按"差分与求和 → 差分方程与算子法"组织。

## 学习路径

1. [差分与求和](01_差分与求和/README.md)：前向与后向差分 $\Delta,\nabla$、移位算子 $E$、离散基本定理与望远镜求和。
2. [差分方程与算子法](02_差分方程与算子法/README.md)：$P(E)y_n=f_n$ 的算子框架（总论、齐次解、特解）与连续对照。

## 与微分方程的关系

本区是 `07_常微分方程/03_线性常系数与算子法` 的**离散镜像**。两边共享同一套推理骨架：

$$
\text{线性与可交换性}
\;\to\;
\text{特征函数}
\;\to\;
\text{特征方程与重根}
\;\to\;
\text{齐次基本解}
\;\to\;
\text{共振修正}.
$$

差别集中在三处：

| 差异 | 连续（$D$） | 离散（$E$） |
| --- | --- | --- |
| 特征函数的自变量 | $e^{\lambda x}$，$\lambda$ 可任取 | $r^{n}$，$r=e^{\lambda}$ |
| 几何因子的分离 | 参数平移 $P(D+\lambda)$ | 参数缩放 $P(rE)$ |
| 稳定区 | 左半平面 $\operatorname{Re}\lambda<0$ | 单位圆 $\lvert r\rvert<1$ |

三处差别的来源是同一个恒等式 $E=e^{D}$，即"移位就是 Taylor 展开"。完整对照见 [连续与离散算子对照](02_差分方程与算子法/连续与离散算子对照.md)。

## 记号约定

| 对象 | 推荐记号 | 说明 |
| --- | --- | --- |
| 前向移位算子 | $E$ | $Ey_n=y_{n+1}$，$E^{k}y_n=y_{n+k}$，$E^{0}=I$ |
| 恒等算子 | $I$ | 也写作 $1$，故 $E-I=\Delta$ |
| 前向差分 | $\Delta$ | $\Delta y_n=y_{n+1}-y_n=E-I$ |
| 后向差分 | $\nabla$ | $\nabla y_n=y_n-y_{n-1}=I-E^{-1}$ |
| 滞后算子 | $B$ | $By_n=y_{n-1}=E^{-1}$；时间序列文献常用 |
| 多项式算子 | $P(E)$ | $P(E)=\sum_{j=0}^{m}a_jE^{j}$ |
| 特征多项式 | $P(r)$ | $P(r)=\sum_{j=0}^{m}a_jr^{j}$，与 $P(E)$ 只差变量替换 |
| 方程阶数 | $m$ | $n$ 保留给序列下标，避免与阶数撞号 |
| 齐次通解、特解 | $y^{(h)}_n$、$y^{(p)}_n$ | 与微分方程的 $y_h,y_p$ 对应 |

**约定：本区一律用前移算子 $E$ 书写方程**（$P(E)y_n=f_n$），特征根一并记在 $r$ 平面上。若改用滞后算子 $B$ 或 $z$ 变换书写，特征根取倒数、稳定区翻到单位圆外；混用两套约定是这一领域最常见的错误来源。
