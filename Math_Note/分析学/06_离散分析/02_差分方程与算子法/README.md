# 差分方程与算子法

本节是离散分析的主体：把常系数线性差分方程写成算子形式 $P(E)y_n=f_n$，用特征多项式把求解问题代数化。整条推理链与 `07_常微分方程/03_线性常系数与算子法` 的微分算子法完全平行，因此推荐按同样的顺序读：

- [连续与离散算子对照](连续与离散算子对照.md)：桥梁 $E=e^{D}$、总对照表、三处系数漂移、稳定性的单位圆几何。
- [差分算子核心特性](差分算子核心特性.md)：线性与可交换性、几何数列的特征函数性质、几何因子分离恒等式 $P(E)(r^{n}u_n)=r^{n}P(rE)u_n$、实虚部原则、多项式空间的有限截断。
- [差分算子法求齐次解](差分算子法求齐次解.md)：特征方程 $p(r)=0$ 的根型分类、基本解表、例题与完整推导。

主线可以压缩为

$$
P(E)y_n=f_n
\;\Longrightarrow\;
p(r)=\sum_{j=0}^{m}a_jr^{j}
\;\Longrightarrow\;
\text{根 }\{r_j\}\text{ 与重数}
\;\Longrightarrow\;
y^{(h)}_n=\sum_j r_j^{\,n}\,\bigl(\text{多项式因子}\bigr).
$$

**待补方向**：非齐次项的特解与共振修正（离散版为乘 $n^{k}$，并带 $r^{-k}$ 系数漂移）、可化简的一阶递推（含有理递推的线性化）、生成函数与 $z$ 变换、线性递推的矩阵形式（伴随矩阵与若尔当型，对应 `代数学/07_特征值与谱`）。
