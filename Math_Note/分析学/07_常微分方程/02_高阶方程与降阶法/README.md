# 高阶方程与降阶法

本章处理**不属于常系数线性**的方程——非线性，或变系数。手段不是算子代数，而是**代换把阶数降下来**，直到落进一阶方程，或直接积出。

## 定位：策略，而非类型

降阶法在分类地图上不占任何一格，因为它不是方程的类型：

- **起点必是高阶**——一阶方程无从再降；
- **终点必是一阶或直接可积**——收尾靠 [01_一阶方程](../01_一阶方程/README.md)。

## 本章内容

| 篇目 | 结构特征 | 代换 |
| --- | --- | --- |
| [01_降阶法](01_降阶法.md) | 缺变量、全导数、仅依赖某阶导、自治、已知一解 | 见各节 |

正文待补：按结构拆分为 缺变量型、自治与能量积分、线性二阶降阶与参数变易、化为一阶方程组。
