# 变系数线性方程

本章处理系数不是常数的线性方程。一般情形没有闭式解——这是 Picard–Vessiot 理论的结论——但有若干**可通过代换化为常系数**的可解类型。

## 本章内容

| 篇目 | 方程 | 化简方式 |
| --- | --- | --- |
| [01_欧拉方程](01_欧拉方程.md) | $x^ny^{(n)}+a_{n-1}x^{n-1}y^{(n-1)}+\cdots+a_0y=f(x)$ | 令 $x=e^t$，化为常系数 |

本篇给出 Euler 方程的完整推导（欧拉算子 $\theta=x\frac{\mathrm d}{\mathrm dx}$ 与 $x^ky^{(k)}$ 的对应）、指示方程、根型查表与例题；已知一解降阶与参数变易见[降阶法](../02_高阶方程与降阶法/01_降阶法.md)。
