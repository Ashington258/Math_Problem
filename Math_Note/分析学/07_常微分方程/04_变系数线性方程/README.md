# 变系数线性方程

本章处理系数不是常数的线性方程。一般情形没有闭式解——这是 Picard–Vessiot 理论的结论——但有若干**可通过代换化为常系数**的可解类型。

## 本章内容

| 篇目 | 方程 | 化简方式 |
| --- | --- | --- |
| Euler 方程（待补） | $x^ny^{(n)}+a_{n-1}x^{n-1}y^{(n-1)}+\cdots+a_0y=0$ | 令 $x=e^t$，化为常系数 |

正文待补：Euler 方程的完整推导与例题，以及已知一解降阶、参数变易在变系数情形下的系统整理。
