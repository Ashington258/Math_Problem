# 线性常系数与算子法

本章处理**线性常系数**方程 $P(D)y=f(x)$。这是常微分方程中理论最完整、结论最干净的一类：解可由特征多项式**闭式写出**，无须降阶，也无须积分。

## 一条主线

$$
\underbrace{P(D)e^{\lambda x}=P(\lambda)e^{\lambda x}}_{\text{指数特征恒等式}}
\;\Longrightarrow\;
\underbrace{P(D)\bigl(e^{\lambda x}u\bigr)=e^{\lambda x}P(D+\lambda)u}_{\text{指数平移公式}}
\;\Longrightarrow\;D^k
$$

- **指数特征恒等式**把微分方程化成代数方程 $P(\lambda)=0$；
- **指数平移公式**把"以 $\lambda$ 为根"平移到"以 $0$ 为根"，$\lambda$ 的重数 $k$ 于是凸显为算子因子 $D^k$；
- 齐次侧看 $D^k$ 的**核**（得 $x^je^{\lambda x}$），非齐次侧看 $D^k$ 的**作用**（故须乘 $x^k$）——重根与共振由此统一。

## 记法

$P(D)$ 是微分算子，$P(\lambda)$ 是把算子中的 $D$ 换成 $\lambda$ 所得的特征值，$P(D+\lambda)$ 是平移算子。全篇不使用小写 $p$。
