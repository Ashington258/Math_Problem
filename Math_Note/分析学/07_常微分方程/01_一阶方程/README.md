# 一阶方程

本章是**降阶的落地工具**：高阶方程经代换降阶后，几乎都会落到这里。同时它自身也是常微分方程中可解性最完整的一类——只要能积分，就能写出解。

## 本章内容

| 类型 | 识别特征 | 解法要点 |
| --- | --- | --- |
| 可分离变量 | $y'=A(x)B(y)$ | 分离后两边积分 |
| 齐次方程 | $y'=F(y/x)$ | 令 $y=ux$，化为可分离 |
| 一阶线性 | $y'+P(x)y=Q(x)$ | 积分因子 $\mu=e^{\int P\,\mathrm dx}$ |
| 伯努利方程 | $y'+P(x)y=Q(x)y^{\alpha}$（$\alpha\neq0,1$） | 令 $z=y^{1-\alpha}$ 线性化 |

正文待补：四类的推导、通解公式与例题。
