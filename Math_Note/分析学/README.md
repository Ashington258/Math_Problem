## 多元微积分的核心链条

$$
\text{多元函数}
\longrightarrow
\text{全微分}
\longrightarrow
\text{多重积分}
\longrightarrow
\text{曲线/曲面积分}
\longrightarrow
\text{Green、Stokes、Gauss 定理}.
$$

这条链条把“局部导数信息”和“区域或边界上的整体量”联系起来，也是从微积分基本定理走向矢量分析与场论的自然路径。
