# 微积分

本区是单变量微积分：从极限与微分、中值定理、积分技巧，到微积分基本思想的统一视角。

## 目录

1. [极限](01_极限/)：小 $o$ 记号与渐近等价、有界量与无穷小（大）的运算。
2. [微分](02_微分/)：微分与线性近似的几何含义、分布导数（阶跃函数与狄拉克 $\delta$）。
3. [中值定理](03_中值定理/)：中值定理及其证明、例题。
4. [积分](04_积分/)：旋转体体积（圆盘法与柱壳法）、三角函数积分、参数区域二重积分、镜像积分，附坐标微元可视化 notebook。
5. [微积分基本思想](06_微积分基本思想/)：微积分基本定理与广义 Stokes 定理的边界抵消本质。

## 与相邻章节的关系

- [02_多元微积分](../02_多元微积分/README.md)：Green、Stokes、Gauss 定理是第 5 节"边界抵消"视角的多维实现，也是 `04_复分析` 中 Cauchy 定理的入口。
- [07_常微分方程](../07_常微分方程/README.md)：常系数线性方程的算子法已独立成章，从本章移出。
- [06_离散分析](../06_离散分析/README.md)：微分方程的离散镜像。$D$ 与 $E$、$\int$ 与 $\sum$、左半平面与单位圆的逐条对应见 [连续与离散算子对照](../06_离散分析/02_差分方程与算子法/连续与离散算子对照.md)。
