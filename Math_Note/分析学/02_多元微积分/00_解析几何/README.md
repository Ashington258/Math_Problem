# 解析几何基础

本章为多元微积分、曲线曲面积分和矢量分析补充必要的解析几何语言。重点不是记忆孤立的方程，而是理解几何对象的三种描述：

- **参数描述**：给出对象如何被参数生成，适合求切向量、弧长和积分；
- **显式描述**：把一个变量写成其他变量的函数，适合局部图像和偏导数；
- **隐式描述**：用方程的等值集合刻画对象，适合求梯度、法向量和切平面。

## 学习路径

1. 点、向量与距离；
2. 直线、线段与射线；
3. 平面与超平面；
4. 空间曲线及其局部几何量；
5. 曲面及三种表示；
6. 切空间、法向量与切平面；
7. 坐标系、定向与后续微积分的接口。

## 与后续章节的连接

- 点到点的位移向量是方向导数和全微分中的增量向量；
- 参数曲线是曲线积分的对象；
- 参数曲面与法向量是曲面积分和通量的基础；
- 梯度垂直于等值面，正是隐式曲面求切平面的核心；
- Jacobian 描述参数变换对长度、面积和体积元素的影响。
