# 切向量与切空间：配图说明

配套正文：[切向量与切空间](../../切向量与切空间.md)。

[旧版切向量与切线配图](../切向量与切线/README.md) 作为历史资料保留，当前正文使用本目录的三组重绘图。

三组图均由解析公式生成，无外部数据、随机采样或手工图像修改。所有坐标、参数和向量分量均无量纲，不涉及测量误差或统计区间。

| 文件主干 | 内容 | PDF/SVG 实际宽 × 高 |

名义宽度为 178 mm 双栏宽度，紧边界导出后含约 1 mm 留白，偏差约 0.6%。PNG 为 600 dpi，正文嵌入 PNG；同时提供 PDF、SVG 矢量版本。`export_sizes.json` 记录每个文件的实际导出尺寸。

中文使用 Microsoft YaHei，数学符号使用 Arial，正文尺寸为 8 pt，最小刻度字号为 6.5 pt。图中采用 Okabe–Ito 蓝、橙和深灰，基本切向量同时以实线、虚线区分，法向量采用点划线，向量相加的辅助线采用点线。三组图均有彩图与灰度预览。

## 数学与尺度

- 图 1：$\mathbf r(x)=(x,x^2/2)$，$p=(1,1/2)$，$\mathbf r'(1)=(1,1)$。橙色箭头是实际位移，蓝色箭头是导数向量，两者没有归一化为单位向量。
- 图 2、3：$\mathbf r(u,v)=(u,v,(u^2+v^2)/2)$，$\mathbf u_0=(1/2,1/2)$，$p=(1/2,1/2,1/4)$。基本切向量为 $(1,0,1/2)$、$(0,1,1/2)$。
- 黑色组合向量为 $0.7\mathbf r_u+0.6\mathbf r_v=(0.7,0.6,0.65)$。脚本检查基本切向量线性无关，并验证组合向量与法向量正交。
- 图 3 的法向量箭头统一绘为 $0.85\mathbf n$，其中 $\mathbf n=(-1/2,-1/2,1)$，该缩放仅便于排版；正文给出未缩放的法向量。
- 二维坐标轴等比例；三维图使用正交投影，并按数据范围设置 `set_box_aspect`，使各方向单位尺度一致。平面只绘制有限片段，切平面与切空间实际无限延伸。

## 复现与校验

在本目录运行：

```powershell
python make_figures.py
node verify_note.cjs (Join-Path $env:TEMP 'math-note-katex-check/node_modules/katex')
```

绘图依赖 Python、NumPy、Matplotlib、Pillow。生成环境：Python 3.13.13、NumPy 2.5.3、Matplotlib 3.11.2、Pillow 12.3.0。`sci_style.py` 为 sci-plot 技能样式模块的本地副本，绘图脚本不依赖原技能的安装位置。

`make_figures.py` 完整生成三组 PNG/PDF/SVG、彩图和灰度预览、导出尺寸记录；`verify_note.cjs` 使用 KaTeX 严格解析正文公式并检查正文链接与图片路径。

本次检查：三组彩图及灰度预览均已目视核对；正文 238 处公式通过 KaTeX 0.16.22 严格解析，正文链接及三张嵌入图片的目标全部存在。
