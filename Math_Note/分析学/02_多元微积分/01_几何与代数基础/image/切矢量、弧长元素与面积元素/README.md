## 数学与尺度

- 图 1：两点为 $P_0=(1,0.4)$、$P_1=(2,1.6)$，位移为 $(1,1.2)$。两个位置矢量从原点出发；位移从起点指向终点，平移位移不改变其大小或方向。
- 图 2 按用户给出的空间曲线图例重画：$\mathbf r(t)=(0.6\sin(2t),t+0.7,0.55t+0.4\sin t+0.9)$，取 $t_0=0.6$。左图绘出 $\mathbf r(t_0)$、$\mathbf r(t_0+1.1)$、两者之差及真实导数；右图比较 $h=1.1,0.55,0.15$ 的差商与导数。两行正交投影基正交归一，全部向量使用同一投影，未独立归一化或拉长。
- 图 3A 的一阶位移为 $(0.5,0.5)$，有限位移为 $(0.5,0.625)$，两者不同。图 3B 使用空间螺线 $(\cos t,\sin t,t/2)$，取 $t_0=0.6$、$h=0.7$，箭头为 $\mathbf r'(t_0)h$。
- 图 4A 的梯度及切向箭头统一按原长的 $0.55$ 缩放，切向箭头标注单位方向 $\mathbf T$；图 4B 的两梯度及叉积统一缩放为原长的 $0.6$。这些缩放在正文图注中明确说明。
- 图 5、6 使用 $\mathbf r(u,v)=(u,v,(u^2+v^2)/2)$，在 $(u_0,v_0)=(1/2,1/2)$ 处，两个偏导为 $(1,0,1/2)$、$(0,1,1/2)$，叉积为 $(-1/2,-1/2,1)$。
- 图 6 使用 $h=0.6$、$k=0.5$，同时画出切平面平行四边形和实际曲面片边界；它们的面积一般不同，仅在微分极限中由一阶平行四边形给出面积微元。叉积箭头为 $hk\,(\mathbf r_u\times\mathbf r_v)$。
- 图 7 使用平面片 $z=x/2+y/2+0.6$，投影因子为 $\sqrt{2/3}$。右图竖直截面沿最陡方向，包含真实法向量；左图法向箭头按 $0.55\mathbf n$ 绘制，右图法向与竖直箭头均长 $0.7$。
- 二维坐标等比例，三维图采用正交投影和与数据范围匹配的盒体纵横比。有限位移与一阶微分、导数向量与单位向量分别在正文或图注中区分。
