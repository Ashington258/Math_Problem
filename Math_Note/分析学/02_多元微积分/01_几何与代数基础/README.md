# 几何与代数基础

本部分为后面的微分、积分、曲线曲面积分和场论提供空间语言与工具。目标是建立「空间感」和向量语言，而不是记忆孤立公式。

## 学习路径

1. **向量代数**
   - 向量的线性运算、线性相关/无关
   - 点积、叉积、混合积（几何意义与代数运算）
   - 向量方程表示直线与平面
2. **空间解析几何**
   - 空间直角坐标系、距离、夹角
   - 平面、直线、二次曲面（柱面、旋转曲面、椭球面、双曲面、抛物面）
   - 曲面与曲线的参数方程、隐式方程
3. **向量值函数（空间曲线）**
   - 空间曲线、切向量与法向量
   - 弧长、曲率、挠率
   - 为曲线积分、曲面积分、散度与旋度做铺垫

> **顺序建议**：先向量代数 → 空间解析几何 → 向量值函数。

## 三种描述方式

几何对象有三种互补的描述，用哪一种取决于要计算什么：

- **参数描述**：给出对象如何被参数生成，适合求切向量、弧长和积分；
- **显式描述**：把一个变量写成其他变量的函数，适合局部图像和偏导数；
- **隐式描述**：用等值集合刻画对象，适合求梯度、法向量和切平面。

## 与后续章节的连接

- 点到点的位移向量是方向导数和全微分中的增量向量；
- 参数曲线是曲线积分的对象；
- 参数曲面与法向量是曲面积分和通量的基础；
- 梯度垂直于等值面，正是隐式曲面求切平面的核心；
- Jacobian 描述参数变换对长度、面积和体积元素的影响。
