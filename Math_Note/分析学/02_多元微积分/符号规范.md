# 多元微积分符号规范

本章正文、公式、图注和当前使用的配图脚本，统一遵循[《切矢量、弧长元素与面积元素》](01_几何与代数基础/切矢量、弧长元素与面积元素.md)第 0 节的约定。几何基础、多元微分学、多元积分学使用同一套记号。

## 1. 几何量与微元

| 几何量 | 统一符号 | 含义 |
| --- | --- | --- |
| 位置矢量 | $\mathbf r$ | 指向几何点的位置矢量 |
| 切矢量 | $\mathbf r'(t)$；多参数时 $\mathbf r_{u_i}=\partial\mathbf r/\partial u_i$ | 位置矢量相对于所选参数的变化率；不要求模长为 1 |
| 单位切矢量 | $\mathbf T=\mathbf r'/\lVert\mathbf r'\rVert$ | 沿所选取向的单位切方向 |
| 曲面法方向 | $\mathbf r_u\times\mathbf r_v$ 或 $\nabla F$ | 直接写出叉积或梯度，不另设简写符号；不要求模长为 1 |
| 单位法向量 | $\mathbf n=\dfrac{\mathbf r_u\times\mathbf r_v}{\lVert\mathbf r_u\times\mathbf r_v\rVert}$ | 根据取向选择正负，模长为 1 |
| 平面法向量 | $\mathbf N$ | 平面方程与点到平面距离使用，见[解析几何基础](01_几何与代数基础/解析几何基础：直线、平面、曲线与曲面.md) |
| 标量弧长元素 | $\mathrm ds$ | 非负长度微元 |
| 矢量弧长元素 | $\mathrm d\mathbf s=\mathrm d\mathbf r=\mathbf T\,\mathrm ds$ | 沿曲线取向的位移微元 |
| 参数方向位移分量 | $\mathrm d\mathbf r_{u_i}=\mathbf r_{u_i}\,\mathrm du_i$ | 沿单个参数方向的位移分量；不是某个函数的全微分 |
| 平面面积元素 | $\mathrm dA$ | 非负平面面积微元 |
| 标量曲面面积元素 | $\mathrm dS$ | 非负曲面面积微元 |
| 矢量曲面面积元素 | $\mathrm d\mathbf S=\mathbf n\,\mathrm dS$ | 法方向与面积的组合 |
| 体积元素 | $\mathrm dV$ | 非负体积微元 |

小写 $s$ 表示弧长，大写 $S$ 表示面积；普通向量用粗体拉丁字母。一般方向向量仍可用 $\mathbf a,\mathbf b,\mathbf u$，物理速度场仍可用 $\mathbf v$；表示切矢量时直接写位置矢量的导数，曲线用 $\mathbf r'(t)$，曲面用 $\mathbf r_u,\mathbf r_v$，不另设简称（部分教材用 $\tau$ 表示单位切矢量，本文不采用）。不把未经归一化的法向量写作 $\mathbf n$，也不把未经归一化的切矢量写作 $\mathbf T$。

## 2. 微分、参数与取向

微分号统一直立：$\mathrm df$、$\mathrm dx$、$\mathrm dt$、$\mathrm d\mathbf r$。有限变化仍用 $\Delta$，例如 $\Delta\mathbf r=\mathbf r(t+h)-\mathbf r(t)$。切矢量由变化率的极限得到：

$$
\mathbf r'(t)=\lim_{h\to0}\frac{\mathbf r(t+h)-\mathbf r(t)}{h}.
$$

沿递增参数书写时，$\mathrm ds=\lVert\mathbf r'(t)\rVert\,\mathrm dt$；一般长度微元用 $\lVert\mathbf r'(t)\rVert\,|\mathrm dt|$。坐标微分可以带符号，标量长度和面积微元非负。反转取向改变矢量微元的方向，不改变标量微元的大小。

曲线积分可直接使用 $\mathrm d\mathbf r$，需要对照标量、矢量弧长元素时同时写出 $\mathrm d\mathbf s=\mathrm d\mathbf r$。曲面通量使用单位法向量配实际面积 $\mathbf n\,\mathrm dS$，或者直接使用叉积配参数面积 $(\mathbf r_u\times\mathbf r_v)\,\mathrm du\,\mathrm dv$，不可混用两个面积因子。

## 3. 其他记号与图文一致性

- 直角坐标基使用 $\mathbf i,\mathbf j,\mathbf k$，一般维数的标准基仍用 $\mathbf e_i$。
- 梯度、散度、旋度分别写为 $\nabla f$、$\nabla\cdot\mathbf F$、$\nabla\times\mathbf F$；方向导数使用 $D_{\mathbf u}f$，其中 $\mathbf u$ 为单位向量。
- 一般坐标变换用 $\mathbf X(\mathbf u)$ 等记号，避免与单位切矢量 $\mathbf T$ 重名。
- 正文允许单字母写成 `\mathbf r`；Matplotlib mathtext 中写 `\mathbf{r}`。二者表示同一个粗体向量，不构成符号差异。
- 范数使用 $\lVert\mathbf v\rVert$ 或 $\|\mathbf v\|$；表格内避免裸竖线破坏分列。矩阵转置、Jacobian 等未在本文第 0 节约束的记号，保留既有约定。
- 配图若将箭头乘以显示比例，图注须说明；不得把缩放后的法向箭头称为单位法向量，也不得将有限弦位移直接当作切矢量。

隐藏归档与明确标注的历史配图保留原貌，当前正文使用本规范。
