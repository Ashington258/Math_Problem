## 重现与输出规格

依赖 Python、NumPy、Matplotlib、Pillow。在本目录运行：

    python make_figures.py

[生成脚本](make_figures.py) 输出本目录全部十组图，使用从 sci-plot 技能复制的本地 sci_style.py。全部数据来自解析公式，无随机数、测量数据或误差带。

仅重现线元图并刷新尺寸清单、预览图，可运行 `python make_figures.py --only line-elements`。图 7 为 178 × 90 mm 的抽象双联图，使用微软雅黑（回退到 SimHei）标注：A 用单位切向指定方向、用弧长微元指定长度；B 展示同一位移的正交投影与分量首尾合成。图中不指定曲线方程、场或数值；箭长为几何示意。

每组输出矢量 PDF、SVG 和 600 dpi PNG，标称宽度 **178 mm**，高度为 90–169 mm；本次三组通量图高度分别为 109、111、112 mm。实际尺寸见 figure_manifest.json，脚本检查宽度偏差小于 3%。preview-1.png 至 preview-5.png 为彩图总览，对应 -gray.png 为灰度总览。

采用 DejaVu Sans、8 pt 正文、7 pt 三维刻度、Okabe–Ito 配色；颜色同时由线型、标记或标签编码。所有示意数值均无量纲，dim. 表示 dimensionless；物理速度、流率和功的单位由正文的场定义决定。

三维图使用正交投影，各空间轴保持相同长度尺度。微元箭头可为阅读单独缩放，具体含义由正文图注说明；正交分解图中的分量使用同一尺度。曲面微片与切平行四边形须区分，后者给出当前点精确的积分密度；斜棱柱与线性参数片的有限体积、面积及投影数值则是精确的。
