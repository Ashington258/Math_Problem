# 积分定理的统一视角

- 微积分基本定理：区间上的导数与边界值
- Green 公式：平面区域上的边界环流/通量与二重积分
- Stokes 公式：曲面边界上的环流与旋度通量
- Gauss 散度定理：闭曲面通量与体积分中的散度
- 定向、边界与“局部微分 = 整体边界效应”
- 微分形式视角下的广义 Stokes 定理

核心结构可概括为：

$$
\int_{\partial \Omega} \omega = \int_{\Omega} \mathrm d\omega.
$$

在不同维度和不同阶数的微分形式下，它分别产生上述经典积分定理。
