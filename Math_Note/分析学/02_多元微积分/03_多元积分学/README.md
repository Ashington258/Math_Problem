# 多元积分学

多元积分学的逻辑主线是：**从简单区域到一般区域，从标量到向量，从低维到高维，最后用三大定理统一**。

以 [多元积分学速查](多元积分学速查.md) 为总览，各专题按“核心概念 → 公式与适用条件 → 例题 → 注意事项”展开，衔接微分学中的梯度、散度与旋度。

各篇配套原理图与例题图，依次展示区域分割、切片、换元、切向投影、曲面面积元、定向、通量、边界相消、补线成闭路与势函数。[配图目录与生成脚本](image/积分学配图/README.md) 提供 22 幅共享图的矢量 PDF、600 dpi PNG 及重现方式；[曲线积分专题配图](02_曲线积分/image/曲线积分/README.md) 另提供 9 组图。

[积分定理专题配图](04_三大积分定理/image/积分定理/README.md) 另提供 9 组重绘图，重点展示区域维数、三维边界、旋度法向投影、封闭曲面的通量及奇点条件。

[积分元素](01_重积分/积分元素.md) 是各类积分的共同前置：统一标量长度、面积、体积与有向位移、有向面积，说明坐标展开、点积与叉积，并提供完整参数化示例。

## 脉络

```
重积分（二重 → 三重）
    ↓
曲线积分（第一型 → 第二型）
    ↓
曲面积分（第一型 → 第二型）
    ↓
三大积分定理（Green → Stokes → Gauss）
    ↓
场论综合应用（保守场、势函数、通量、环流量）
```

## 学习路径

1. **重积分**
   - 二重积分：定义、性质、计算（直角坐标、极坐标）
   - 三重积分：定义、计算（直角、柱面、球面坐标）
   - 重积分的换元公式（Jacobian）
   - 应用：体积、质量、质心、转动惯量、引力
2. **曲线积分**
   - 第一型（对弧长）：标量线积分
   - 第二型（对坐标）：向量线积分
   - 两者关系、计算、与路径无关的条件
3. **曲面积分**
   - 第一型（对面积）：标量面积分
   - 第二型（对坐标）：向量面积分（通量）
   - 计算与定向
4. **三大积分定理**
   - Green 公式（平面）
   - Stokes 公式（空间曲线与曲面）
   - Gauss 散度定理（封闭曲面与体积）
   - 统一视角：微分形式下的广义 Stokes 定理
5. **场论综合**
   - 保守场、无源场、无旋场的判定
   - 势函数的求法
   - 物理应用（功、环流量、通量、连续性方程）
