# 多元积分学

多元积分学的逻辑主线是：**从简单区域到一般区域，从标量到向量，从低维到高维，最后用三大定理统一**。

## 脉络

```
重积分（二重 → 三重）
    ↓
曲线积分（第一型 → 第二型）
    ↓
曲面积分（第一型 → 第二型）
    ↓
三大积分定理（Green → Stokes → Gauss）
    ↓
场论综合应用（保守场、势函数、通量、环流量）
```

## 学习路径

1. **重积分**
   - 二重积分：定义、性质、计算（直角坐标、极坐标）
   - 三重积分：定义、计算（直角、柱面、球面坐标）
   - 重积分的换元公式（Jacobian）
   - 应用：体积、质量、质心、转动惯量、引力
2. **曲线积分**
   - 第一型（对弧长）：标量线积分
   - 第二型（对坐标）：向量线积分
   - 两者关系、计算、与路径无关的条件
3. **曲面积分**
   - 第一型（对面积）：标量面积分
   - 第二型（对坐标）：向量面积分（通量）
   - 计算与定向
4. **三大积分定理**（向量分析的高潮）
   - Green 公式（平面）
   - Stokes 公式（空间曲线与曲面）
   - Gauss 散度定理（封闭曲面与体积）
   - 统一视角：微分形式下的广义 Stokes 定理
5. **场论综合**
   - 保守场、无源场、无旋场的判定
   - 势函数的求法
   - 物理应用（功、环流量、通量、连续性方程）
