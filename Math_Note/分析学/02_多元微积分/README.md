# 多元微积分

多元微积分研究多变量函数的局部变化、区域上的累积，以及局部微分信息如何通过边界积分表现出来。

## 学习主线

1. **多元函数与极限**：从平面和空间中的邻域、路径与连续性开始。
2. **多元微分与全微分**：偏导数、方向导数、梯度、Jacobian、全微分与线性近似。
3. **二重与三重积分**：区域描述、累次积分、Fubini 定理、变量代换与几何应用。
4. **曲线与曲面积分**：参数曲线、第一类/第二类积分、参数曲面与通量。
5. **矢量分析与场论**：梯度、散度、旋度、势函数、保守场与无散场。
6. **积分定理的统一视角**：Green 公式、Stokes 公式、Gauss 散度定理，以及它们与微积分基本定理的关系。

## 建议的统一语言

先用坐标形式建立计算直觉，再逐步引入映射、Jacobian、定向、微分形式和流形。这样既能服务于计算，也能解释为什么多个积分公式具有同一个结构。
