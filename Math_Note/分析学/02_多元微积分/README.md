# 多元微积分

多元微积分研究多变量函数的局部变化、区域上的累积，以及局部微分信息如何通过边界积分表现出来。

整体按**几何与代数基础 → 多元微分学 → 多元积分学**三部分展开：先建立空间与向量语言，再从局部线性近似扩展出微分学，最后用微分算子解释积分定理，形成闭环。

## 目录

1. [01_几何与代数基础](01_几何与代数基础/README.md)：向量代数、空间解析几何与向量值函数，为后续微分、积分提供语言与工具。
2. [02_多元微分学](02_多元微分学/README.md)：极限与连续、偏导数、全微分与可微性、链式法则与隐/反函数定理、方向导数与梯度、极值理论、向量微分算子。
3. [03_多元积分学](03_多元积分学/README.md)：重积分、曲线积分、曲面积分、三大积分定理（Green/Stokes/Gauss）与场论应用。

## 核心链条

$$
\text{几何与代数基础}
\longrightarrow
\text{多元函数与极限}
\longrightarrow
\text{偏导数与全微分}
\longrightarrow
\text{方向导数与梯度}
\longrightarrow
\text{重积分}
\longrightarrow
\text{曲线/曲面积分}
\longrightarrow
\text{Green、Stokes、Gauss 定理}.
$$

这条链条把「局部导数信息」和「区域或边界上的整体量」联系起来，也是从微积分基本定理走向矢量分析与场论的自然路径。

## 为什么是这个顺序

| 部分 | 依赖关系 | 认知优势 |
|------|----------|----------|
| 几何与代数基础 | 无前置 | 先建立「空间感」和向量语言 |
| 多元微分学 | 依赖几何基础 + 一元微积分 | 从局部线性近似逐步扩展 |
| 多元积分学 | 依赖微分学（梯度、散度、旋度） | 用微分算子解释积分定理，形成闭环 |

## 建议的统一语言

先用坐标形式建立计算直觉，再逐步引入映射、Jacobian、定向、微分形式和流形。这样既能服务于计算，也能解释为什么多个积分公式具有同一个结构。
