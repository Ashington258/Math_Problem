# 多元微分学

本部分从多元函数的极限与连续出发，逐层建立局部线性近似（全微分）与导数结构，最后引入向量微分算子。

## 脉络

```
多元函数与极限连续性
    ↓
偏导数
    ↓
全微分与可微性（核心）
    ↓
链式法则 + 隐函数/反函数定理
    ↓
方向导数与梯度
    ↓
极值理论（无约束 + 拉格朗日乘数法）
    ↓
向量场的微分算子（梯度、散度、旋度、Laplace）
```

## 学习路径

1. **多元函数、极限与连续性**
2. **偏导数**（一阶、高阶、Clairaut 定理）
3. **全微分与可微性**（线性近似、切平面/切超平面）
4. **链式法则**、**隐函数定理与反函数定理**
5. **方向导数与梯度**
6. **极值问题**
   - 无约束：临界点 + Hessian 判别
   - 有约束：拉格朗日乘数法
7. **向量微积分的微分部分**
   - 梯度、散度、旋度及其恒等式（Laplace 算子、坐标变换下的表达式）
