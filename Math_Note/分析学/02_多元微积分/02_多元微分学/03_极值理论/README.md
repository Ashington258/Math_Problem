# 极值理论

本部分研究多元函数的极值：无约束情形用 Hessian 判别，有约束情形用拉格朗日乘数法。

## 学习路径

1. 驻点、极值点、鞍点与「拐点」的本质区别；
2. 一阶必要条件（Fermat 定理的多元版本）；
3. 二阶充分判据：Hessian 正定 / 负定 / 不定；
4. 无约束极值：临界点 + Hessian 判别（含 $D=0$ 退化情形的处理）；
5. 有约束极值：拉格朗日乘数法。
