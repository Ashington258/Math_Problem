# 二阶判别法

> Hessian 矩阵、二次型与 Sylvester 判据

本文讨论无约束极值的二阶充分条件：从 Hessian 的二次型出发，经谱分解与合同对角化，把特征值的符号问题化为顺序主子式的符号问题。计算流程与例题见 [用 Hessian 矩阵求二元函数无条件极值](用Hessian矩阵求二元函数无条件极值.md)，概念定位见 [极值点、拐点与驻点的本质定义（多元函数版）](极值点、拐点与驻点的本质定义（多元函数版）.md)，二次型、惯性与正定判据的代数背景见 [二次型的正定性与惯性定理](../../../../代数学/08_二次型与合同/二次型的正定性与惯性定理.md)。

## 核心逻辑

\[
\boxed{
\text{驻点} \xrightarrow{\text{Taylor 展开}} \text{二次型} \xrightarrow{\text{谱分解}} \text{特征值符号} \xrightarrow{\text{合同对角化}} \text{顺序主子式} \xrightarrow{\text{Sylvester 判据}} \text{极值判定}
}
\]

设 \(f:\mathbb R^n\to\mathbb R\) 在 \(\mathbf x_0\) 的邻域内二阶连续可微。若 \(\mathbf x_0\) 为驻点，则

\[
\nabla f(\mathbf x_0)=\mathbf 0
\]

由二阶 Taylor 展开：

\[
f(\mathbf x_0+\mathbf h) =f(\mathbf x_0) +\nabla f(\mathbf x_0)^{\mathsf T}\mathbf h +\frac12\mathbf h^{\mathsf T}H\mathbf h +o(\|\mathbf h\|^2)
\]

其中 \(H=\nabla^2 f(\mathbf x_0)\) 称为 Hessian 矩阵（海森矩阵）：

\[
H=
\left[ \frac{\partial^2 f}{\partial x_i\partial x_j}(\mathbf x_0) \right]_{n\times n}
\]

由于一阶项为零：

\[
\boxed{
\Delta f =f(\mathbf x_0+\mathbf h)-f(\mathbf x_0)
=\frac12\mathbf h^{\mathsf T}H\mathbf h +o(\|\mathbf h\|^2)
}
\]

因此，若二次型

\[
\boxed{Q(\mathbf h)=\mathbf h^{\mathsf T}H\mathbf h}
\]

正定，则 \(\mathbf x_0\) 为严格局部极小值点；若负定，则为严格局部极大值点。

问题由函数的极值判定，转化为二次型的正负定性判定。

由于 \(f\in C^2\)，混合偏导数相等，故 Hessian 为实对称矩阵：

\[
H=H^{\mathsf T}
\]

根据实对称矩阵的谱定理，存在正交矩阵 \(P\)，使得

\[
P^{\mathsf T}HP
=\Lambda
=\operatorname{diag}(\lambda_1,\ldots,\lambda_n)
\]

令 \(\mathbf y=P^{\mathsf T}\mathbf h\)，则

\[
\begin{aligned}
Q(\mathbf h)
&=\mathbf h^{\mathsf T}H\mathbf h\\
&=\mathbf y^{\mathsf T}\Lambda\mathbf y
\end{aligned}
\]

即

\[
\boxed{Q=\lambda_1y_1^2+\cdots+\lambda_ny_n^2}
\]

由于 \(y_i^2\ge0\)，且正交变换为可逆变换，因此：

| 特征值条件 | 二次型性质 | 驻点性质 |
|---|---|---|
| \(\lambda_i>0,\ \forall i\) | 正定 | 严格局部极小值 |
| \(\lambda_i<0,\ \forall i\) | 负定 | 严格局部极大值 |
| 存在正、负特征值 | 不定 | 鞍点 |
| 存在零特征值，且无正负混合 | 半正定或半负定 | 二阶判别法无法确定 |

**本质**：特征值刻画函数沿各正交主方向的二阶变化率，其符号决定二次型的正负定性。

求全部特征值可能较复杂。实际上，我们只需判断其正负，而不需要具体数值。为此，可以通过对称消元（等价于二次型配方法），将 Hessian 合同对角化：

\[
\boxed{EHE^{\mathsf T}=D}
\]

其中 \(E\) 为可逆矩阵，\(D\) 为对角矩阵。

合同变换就是将初等行变换与对应的初等列变换配套进行：左乘 \(E\)，同时右乘 \(E^{\mathsf T}\)。

根据 Sylvester 惯性定律：

> 实对称矩阵在可逆合同变换下，正、负、零特征值的个数保持不变。

因此，虽然 \(D\) 的对角元不一定等于 \(H\) 的特征值，但其正负分布与 \(H\) 的特征值一致。

先看二阶情形，设 \(a\ne0\)。首先进行初等行变换：

\[
\begin{pmatrix}a&b\\b&c\end{pmatrix}
\xrightarrow{R_2\leftarrow R_2-\frac baR_1}
\begin{pmatrix}a&b\\0&c-\frac{b^2}{a}\end{pmatrix}.
\]

再进行对应的初等列变换：

\[
\begin{pmatrix}a&b\\0&c-\frac{b^2}{a}\end{pmatrix}
\xrightarrow{C_2\leftarrow C_2-\frac baC_1}
\boxed{\begin{pmatrix}a&0\\0&c-\frac{b^2}{a}\end{pmatrix}}.
\]

此时顺序主子式为 \(\Delta_1=a\)、\(\Delta_2=ac-b^2\)，因此两个对角元恰好是

\[
d_1=a=\Delta_1,\qquad
d_2=c-\frac{b^2}{a}=\frac{ac-b^2}{a}=\frac{\Delta_2}{\Delta_1}.
\]

推广到一般阶数：先以左上角元素为主元，消去第一列下方元素，再做配套列变换，使第一行右侧元素也为零；随后对右下角剩余矩阵重复同样操作。若各步所需主元均非零，就得到

\[
EHE^{\mathsf T}=D=\operatorname{diag}(d_1,\ldots,d_n),
\]

其中 \(E\) 是各次行变换矩阵的乘积，为单位下三角矩阵。

记 \(H\) 的前 \(k\) 阶顺序主子式为

\[
\Delta_k=\det H_k,\qquad \Delta_0=1
\]

由于单位下三角消元不会将后面的行、列混入前面，记 \(E_k,D_k\) 为相应的前 \(k\) 阶块，则

\[
D_k=E_kH_kE_k^{\mathsf T}
\]

且 \(\det E_k=1\)，因此

\[
\begin{aligned}
\Delta_k
&=\det H_k\\
&=\det D_k\\
&=d_1d_2\cdots d_k
\end{aligned}
\]

从而

\[
\boxed{d_k=\frac{\Delta_k}{\Delta_{k-1}}}
\]

最终得到

\[
\boxed{
H\xrightarrow{\text{合同变换}}
D=\operatorname{diag}\left(
\Delta_1,\
\frac{\Delta_2}{\Delta_1},\
\frac{\Delta_3}{\Delta_2},\
\ldots,\
\frac{\Delta_n}{\Delta_{n-1}}
\right)
}
\]

其中要求 \(\Delta_1,\ldots,\Delta_{n-1}\ne0\)。

**关键结论**：对称消元既保持矩阵的惯性，又保持各阶顺序主子式；而对角矩阵的主子式等于对角元的累积乘积，因此必然出现相邻主子式之比。

由惯性定律：

\[
H\text{ 正定} \iff d_k>0,\quad \forall k
\]

结合

\[
d_k=\frac{\Delta_k}{\Delta_{k-1}}
\]

即可得到 Sylvester 正定、负定判据：

### （1）正定判据

\[
\boxed{
H\text{ 正定} \iff \Delta_k>0,\quad k=1,\ldots,n
}
\]

即顺序主子式全部为正：

\[
\boxed{+,+,+,\ldots,+}
\]

对应严格局部极小值。

### （2）负定判据

\[
\boxed{
H\text{ 负定} \iff (-1)^k\Delta_k>0,\quad k=1,\ldots,n
}
\]

即顺序主子式奇负偶正：

\[
\boxed{-,+,-,+,\ldots}
\]

对应严格局部极大值。

### （3）不定情形

若 Hessian 同时存在正、负特征值，则二次型不定，驻点为鞍点。

> **注意**：正定、负定判据不成立，并不必然意味着不定。若存在零特征值，则可能需要考虑更高阶项。

\[
\boxed{
\begin{gathered}
\nabla f(\mathbf x_0)=0\\[4pt]
\Downarrow\quad\text{Taylor 展开}\\[4pt]
\Delta f=\frac12\mathbf h^{\mathsf T}H\mathbf h+o(\|\mathbf h\|^2)\\[6pt]
\Downarrow\quad\text{实对称矩阵的谱定理}\\[4pt]
Q=\sum_{i=1}^{n}\lambda_i y_i^2\\[6pt]
\Downarrow\quad\text{合同对角化与惯性定律}\\[4pt]
Q=\sum_{i=1}^{n}d_i z_i^2, \qquad d_i=\frac{\Delta_i}{\Delta_{i-1}}\\[6pt]
\Downarrow\quad\text{Sylvester 判据}\\[4pt]
\begin{cases}
\Delta_k>0,\ \forall k &\Rightarrow\text{严格局部极小值}\\[3pt]
(-1)^k\Delta_k>0,\ \forall k &\Rightarrow\text{严格局部极大值}
\end{cases}
\end{gathered}
}
\]

**核心认识**：Hessian 极值判别法的本质是二次型的符号判定；谱分解通过特征值直接描述其正负定性，而 Sylvester 判据利用合同对角化与惯性不变性，将特征值的符号问题转化为顺序主子式的符号问题。

> **注**：严格正定或负定时，二次型的符号可以控制充分小邻域内的 Taylor 余项，因而保证严格局部极值；半正定、半负定或零矩阵时，仅凭二阶项通常无法完成判定。
