# 符号规范

多元微分学与几何基础、多元积分学统一使用[全章符号规范](../符号规范.md)，以[《切矢量、弧长元素与面积元素》](../01_几何与代数基础/切矢量、弧长元素与面积元素.md)第 0 节为准。

| 几何量 | 统一记号 |
| --- | --- |
| 位置矢量 | $\mathbf r$ |
| 切矢量 | $\mathbf r'(t)$ |
| 单位切矢量 | $\mathbf T=\mathbf r'/\lVert\mathbf r'\rVert$ |
| 曲面法方向 | $\mathbf r_u\times\mathbf r_v$、$\nabla F$ |
| 单位法向量 | $\mathbf n=\mathbf r_u\times\mathbf r_v/\lVert\mathbf r_u\times\mathbf r_v\rVert$ |
| 微分与全微分 | $\mathrm dx$、$\mathrm df$、$\mathrm d\mathbf r$ |
| 弧长与有向线元 | $\mathrm ds$、$\mathrm d\mathbf s=\mathrm d\mathbf r$ |
| 面积与有向面元 | $\mathrm dS$、$\mathrm d\mathbf S=\mathbf n\,\mathrm dS$ |

曲面法方向直接写叉积或梯度，单位法向量使用小写 $\mathbf n$，单位切矢量使用 $\mathbf T$，微分号直立。正文与当前配图同步采用此约定。Matplotlib 中的拉丁向量写作带花括号的形式，以兼容 mathtext 解析。
