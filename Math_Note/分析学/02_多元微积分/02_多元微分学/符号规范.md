# 符号规范

本规范约束 [02_多元微分学](README.md) 全部分册（多元函数与极限、微分与全微分、极值理论）的正文、图注与配图脚本。写作或修改本目录笔记时按本规范执行；微元与区域记号与 [03_多元积分学](../03_多元积分学/README.md) 保持一致，便于跨节引用。

**最规范的国际化符号**（以国际主流教材为准：Stewart *Calculus*、Thomas *Calculus*、Apostol、Marsden *Vector Calculus*、Wikipedia Vector Calculus，以及 ISO／数学文献惯例）

优先使用 **粗体** 表示向量（英文文献最标准），Nabla 算子 $\nabla$ 是核心。中文教材中的 $\operatorname{rot}$、箭头 $\overrightarrow{}$ 等属于地区变体，国际规范中较少使用。

## 1. 强制规则

| 项目 | 本目录采用 | 不采用 | 说明 |
| --- | --- | --- | --- |
| 向量字体 | $\mathbf F$、$\mathbf r$、$\mathbf n$、$\mathbf T$、$\mathbf e_x$ | $\vec F$、$\overrightarrow{F}$、$\boldsymbol F$ | 希腊字母向量仍用 $\boldsymbol\gamma$、$\boldsymbol\Omega$ |
| 粗体写法 | `\mathbf F`（单字母不加花括号） | `\mathbf{F}` | 多字母或带下标才写 `\mathbf e_x`、`\mathbf{F}_2` |
| 数域 | $\mathbb R^n$ | $\mathbb{R}^n$ | 与 [代数学符号体系](../../../代数学/00_总览/符号体系.md) 一致 |
| 基向量 | $\mathbf e_x,\mathbf e_y,\mathbf e_z$、$\mathbf e_i$ | $\mathbf i,\mathbf j,\mathbf k$ | 与和式下标 $\mathbf e_i$、$\delta_{ij}$ 统一 |
| 微分号 | $df$、$d\mathbf r$、$ds$、$dS$、$dV$ | $\mathrm{d}f$、$\text{d}f$ | 不写 `\mathrm` |
| 算子 | $\nabla f$、$\nabla\cdot\mathbf F$、$\nabla\times\mathbf F$ | $\operatorname{rot}\mathbf F$ | `grad`／`div`／`curl` 只作等价写法 |
| Laplace 算子 | $\Delta f$ | — | $\nabla^2 f$ 为等价写法 |
| 方向导数 | $D_{\mathbf u}f$ | $\dfrac{\partial f}{\partial\mathbf u}$ | $\mathbf u$ 为单位向量 |
| 向量场分量 | $P,Q,R$；$\mathbf F=P\mathbf e_x+Q\mathbf e_y+R\mathbf e_z$ | 分量写成粗体 | 分量是标量，保持斜体 |
| 转置 | $A^T$、$\mathbf h^T$ | $A^{\mathsf T}$、$A^{\top}$ | 本目录内不混用两种写法 |
| 范数与绝对值 | 范数 $\lVert\mathbf h\rVert$；绝对值 $\lvert x\rvert$ | 表格单元格内裸竖线 | 竖线会被当成列分隔，表格里统一写 `\lVert` 与 `\rVert` |
| 单位切向量 | $\mathbf T$ | $\mathbf t$ | 弧长参数化时 $\mathbf T=\mathbf r'(s)$ |
| 法向量 | $\mathbf n$；单位法向量 $\hat{\mathbf n}$ | $\mathbf N$ | 参数曲面用 $\mathbf r_u\times\mathbf r_v$ |
| 闭积分 | $\oint_C$、$\oiint_S$ | — | 闭曲线、闭曲面 |
| 算子名 | `\det`、`\operatorname{tr}`、`\operatorname{diag}` | — | 直立字体；LaTeX 内置命令不加 `\operatorname` |

**两条例外。** 一是配图脚本：matplotlib 的 mathtext 解析器要求 `\mathbf` 必须带花括号（写 `\mathbf{F}`，不写 `\mathbf F`），且 `\sqrt3` 必须写成 `\sqrt{3}`；正文规则不变。二是本目录外的笔记（如 [代数学符号体系](../../../代数学/00_总览/符号体系.md) 规定转置写 $A^{\mathsf T}$）沿用其自身规定，跨篇引用时以被引笔记为准。

## 2. 完整符号规范总表

### 2.1 微分操作符（Differential Operators）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 梯度 (Gradient) | $\nabla f$ | $\operatorname{grad} f$ | 标量 → 向量 |
| 散度 (Divergence) | $\nabla \cdot \mathbf F$ | $\operatorname{div} \mathbf F$ | 向量 → 标量 |
| 旋度 (Curl) | $\nabla \times \mathbf F$ | $\operatorname{curl} \mathbf F$ | 向量 → 向量（三维） |
| 方向导数 (Directional derivative) | $D_{\mathbf u} f$ | $\nabla_{\mathbf u} f$、$\frac{\partial f}{\partial \mathbf u}$ | $\mathbf u$ 为单位向量 |
| 全微分 (Total differential) | $df$ | $Df$ | $df = \nabla f \cdot d\mathbf r$ |
| 拉普拉斯算子 (Laplacian) | $\Delta f$ 或 $\nabla^2 f$ | $\nabla \cdot (\nabla f)$ | 最常用 $\Delta f$ |

### 2.2 积分微元（Differential Elements）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 线微元（弧长） | $ds$ | $d\ell$、$\lVert d\mathbf r\rVert$ | 标量 |
| 有向线元 | $d\mathbf r$ | $d\mathbf s$、$\mathbf T\, ds$ | 向量 |
| 面积微元（平面） | $dA$ | $d\sigma$、$dx\, dy$ | 标量 |
| 曲面面积微元 | $dS$ | $d\sigma$ | 标量 |
| 有向曲面元 | $d\mathbf S$ | $\mathbf n\, dS$、$\mathbf N\, dS$ | 向量 |
| 体积微元 | $dV$ | $d\tau$、$dx\, dy\, dz$ | 标量 |

### 2.3 积分区域（Domains of Integration）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 曲线 / 路径 | $C$ 或 $\gamma$ | $L$、$\Gamma$ | 闭曲线常用 $C$ |
| 平面区域 / 投影 | $D$ 或 $R$ | $\Omega$（二维） | 最常用 $D$ |
| 曲面 | $S$ | $\Sigma$、$M$ | 边界 $\partial S$ |
| 体积 / 空间区域 | $V$ 或 $E$ | $\Omega$、$\mathcal V$ | 高斯公式常用 $E$ 或 $V$ |
| 边界 | $\partial$ | — | $\partial D$、$\partial S$、$\partial V$ |

### 2.4 路径切向量（Tangent Vectors to a Path/Curve）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 位置向量（参数曲线） | $\mathbf r(t)$ | $\boldsymbol\gamma(t)$、$\mathbf c(t)$ | $\mathbf r(t) = (x(t),y(t),z(t))$ |
| 切向量（速度向量） | $\mathbf r'(t)$ | $\frac{d\mathbf r}{dt}$、$\mathbf v(t)$ | 最常用 $\mathbf r'(t)$ |
| 单位切向量 | $\mathbf T(t)$ | $\mathbf t$、$\hat{\mathbf T}$ | $\mathbf T = \dfrac{\mathbf r'(t)}{\lVert\mathbf r'(t)\rVert}$ |
| 有向线元 | $d\mathbf r$ | $\mathbf r'(t)\, dt$ | $d\mathbf r = \mathbf T\, ds$ |
| 弧长参数化 | $\mathbf r(s)$ | — | 此时 $\mathbf T = \mathbf r'(s)$ |

### 2.5 平面法向量（Normal Vectors to a Plane）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 法向量 | $\mathbf n$ | $\mathbf N$ | 平面 $Ax+By+Cz+D=0$ 中 $\mathbf n=(A,B,C)$ |
| 单位法向量 | $\hat{\mathbf n}$ 或 $\mathbf n/\lVert\mathbf n\rVert$ | $\mathbf n^0$ | 归一化 |
| 点法式方程 | $\mathbf n \cdot (\mathbf r-\mathbf r_0)=0$ | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ | 最标准向量形式 |
| 由两方向确定 | $\mathbf n = \mathbf u \times \mathbf v$ | — | 叉积 |

### 2.6 曲面相关（Surface Counterparts）

| 概念 | 最规范国际符号 | 常见等价写法 | 备注 |
|------|----------------|--------------|------|
| 参数曲面 | $\mathbf r(u,v)$ | $\mathbf x(u,v)$ | — |
| 法向量（参数形式） | $\mathbf r_u \times \mathbf r_v$ | $\mathbf N$ | 最常用 |
| 单位法向量 | $\mathbf n = \dfrac{\mathbf r_u \times \mathbf r_v}{\lVert\mathbf r_u \times \mathbf r_v\rVert}$ | $\hat{\mathbf N}$ | — |
| 有向曲面元 | $d\mathbf S = (\mathbf r_u \times \mathbf r_v)\, du\, dv$ | $\mathbf n\, dS$ | 通量积分核心 |

## 3. 使用建议（国际化写作）

- **向量**一律用粗体：$\mathbf F$、$\mathbf r$、$\mathbf n$、$\mathbf T$（不用箭头）。
- **算子**优先 $\nabla$：$\nabla f$、$\nabla\cdot\mathbf F$、$\nabla\times\mathbf F$。
- **微元**：线用 $d\mathbf r$ 或 $ds$，面用 $d\mathbf S$ 或 $dS$，体用 $dV$。
- **区域**：曲线 $C$，平面域 $D$，曲面 $S$，体积 $V$ 或 $E$。
- 闭积分：$\oint_C$、$\oiint_S$（或 $\iint_{\partial V}$）。

## 5. 检查清单

1. 新增或改写的向量是否用粗体 `\mathbf`，单字母是否未加花括号；
2. 微分号是否写成 `d`，没有 `\mathrm{d}`；
3. 散度、旋度是否用 $\nabla\cdot$、$\nabla\times$，没有 `\operatorname{rot}`；
4. 微元、区域是否落在第 2 节的符号表内；
5. 同一篇内转置、范数、单位切向量是否只有一种写法；
6. 改到配图脚本时，用带花括号的 `\mathbf{...}`，并重新运行 `python make_figures.py` 生成图件。
