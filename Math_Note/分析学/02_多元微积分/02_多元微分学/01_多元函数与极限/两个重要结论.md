# 两个重要结论


## 极限存在必可微


\[
\boxed{
\lim_{(x,y)\to(0,0)}
\frac{f(x,y)-f(0,0)}{\sqrt{x^2+y^2}}=0
\iff
\begin{cases}
f\text{ 在原点可微},\\
Df(\mathbf0)=0.
\end{cases}
}
\]

$$
\lim_{(x,y)\to(0,0)}\frac{f(x,y)}{\sqrt{x^{2}+y^{2}}}=0
$$

且 f(0,0) = 0,则必然可微

## 多元极限的判别

$$
I=\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{p}y^{q}}{x^{m}+y^{n}},\ \text{若 } m,n \text{ 均为偶数且 } \frac{p}{m}+\frac{q}{n}>1,\ \text{则 } I=0;\ \text{否则 } I \text{ 不存在}
$$

$$
\text{(1)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{2}y^{3}}{x^{3}+y^{3}}\qquad
\text{(2)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{2}y^{3}}{x^{2}+y}\qquad
\text{(3)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{2}y}{x^{4}+y^{2}}
$$

$$
\text{(4)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{3}y^{2}}{x^{4}+y^{6}}\qquad
\text{(5)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{|xy|}{\sqrt{x^{2}+y^{2}}}\qquad
\text{(6)}\lim_{\substack{x\to 0\\ y\to 0}}\frac{x^{2}|y|^{\frac{3}{2}}}{x^{4}+y^{2}}
$$
