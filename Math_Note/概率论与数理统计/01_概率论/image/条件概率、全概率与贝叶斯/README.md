# 条件概率、全概率与贝叶斯配图

配套 [条件概率、全概率与贝叶斯](../../条件概率、全概率与贝叶斯.md)。使用 sci-plot 样式生成，所有数值来自正文模型与解析公式，不使用随机模拟或观测数据，无统计误差条。

| 文件主干 | 内容 |
| --- | --- |
| fig-01-conditioning | 样本空间中的 A、B 两圆与交集；已知 B 后在 B 内归一化 |
| fig-02-partition | 三分区样本空间与横跨分区的椭圆事件 B；逐块求和 |
| fig-03-total-and-bayes | 产量乘不合格率得到交集贡献；先验与后验对照 |
| fig-04-switching-cdf | 独立正态平面分支与对角线分支；联合分布事件 |

在本目录执行：

```powershell
python -m pip install -r requirements.txt
python make_figures.py
```

也可从其他目录用脚本完整路径运行，输出始终写到本目录。`sci_style.py` 是所用 sci-plot 技能样式模块的本地副本，不依赖用户技能目录。中文使用 Microsoft YaHei（回退 SimHei）；在其他系统复现时需安装可用的中文字体并调整脚本字体列表。

每图输出矢量 PDF、SVG 和 600 dpi PNG，名义宽度为双栏 178 mm；实际导出尺寸见 `figure_manifest.json`。所有标注不小于 6 pt。SVG 保留文字，跨设备阅读需有相应字体；PDF 嵌入字体。正文嵌入 PNG，印刷可使用 PDF。

概率、比例、标准正态变量均无量纲；只有概率百分比轴使用 %。图 1、2 是无数据坐标轴的集合示意图，圆、椭圆和各分区面积不对应概率数值；图 3 的矩形面积按模型概率绘制。图 4 的等高线是第一分支的条件密度，对角线线宽不编码密度，两分支权重均为 1/2，窗口外正态尾部仍包含在公式中。

`preview-*.png` 为低分辨率检查预览，`*-gray.png` 为灰度预览。采用白底、低饱和蓝/绿灰/赭色填充和深色边界；图 1 的斜线交集、图 2 的虚线分界、不同纹理与直接标签提供颜色以外的识别。数值图继续采用 Okabe–Ito 蓝橙配色。脚本检查示例算术及导出宽度；图片完全由代码生成。
