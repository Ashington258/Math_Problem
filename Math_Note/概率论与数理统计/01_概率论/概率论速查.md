## 2. 一维随机变量和分布

| 分布 | 分布律 $p_k=P(X=k)$ / 概率密度 $f(x)$ | $\mathbb{E}[X]$ | $\operatorname{Var}(X)$ | 参数与约定 |
| --- | --- | --- | --- | --- |
| [$\operatorname{Bernoulli}(p)$](02_一维随机变量及其分布.md#bernoulli) | $p_0=1-p,\quad p_1=p$ | $p$ | $p(1-p)$ | 取值 $0,1$ |
| [$\operatorname{Binomial}(n,p)$](02_一维随机变量及其分布.md#binomial) | $p_k=\dbinom nkp^k(1-p)^{n-k},\quad k=0,1,\ldots,n$ | $np$ | $np(1-p)$ | $n$ 次独立同参数试验，简记 $B(n,p)$ |
| [$\operatorname{Poisson}(\lambda)$](02_一维随机变量及其分布.md#poisson) | $p_k=e^{-\lambda}\dfrac{\lambda^k}{k!},\quad k=0,1,2,\ldots$ | $\lambda$ | $\lambda$ | $\lambda>0$ |
| [$\operatorname{Geom}(p)$](02_一维随机变量及其分布.md#geometric) | $p_k=(1-p)^{k-1}p,\quad k=1,2,\ldots$ | $1/p$ | $(1-p)/p^2$ | 计数包含首次成功（支持集 $\{1,2,\ldots\}$），$0<p\le1$ |
| [$\operatorname{Hypergeometric}(N,K,n)$](02_一维随机变量及其分布.md#hypergeometric) | $p_k=\dfrac{\dbinom Kk\dbinom{N-K}{n-k}}{\dbinom Nn},\quad \max(0,n-N+K)\le k\le\min(n,K)$ | $nK/N$ | $n\dfrac KN(1-\dfrac KN)\dfrac{N-n}{N-1}$ | 合法抽样参数，$N>1$，简记 $H(N,K,n)$ |
| [$U(a,b)$](02_一维随机变量及其分布.md#uniform) | $f(x)=\begin{cases}\dfrac1{b-a},&a<x<b,\\ 0,&\text{其他}.\end{cases}$ | $(a+b)/2$ | $(b-a)^2/12$ | $a<b$ |
| [$\operatorname{Exp}(\lambda)$](02_一维随机变量及其分布.md#exponential) | $f(x)=\begin{cases}\lambda e^{-\lambda x},&x\ge0,\\ 0,&x<0.\end{cases}$ | $1/\lambda$ | $1/\lambda^2$ | $\lambda>0$ 为速率参数 |
| [$N(\mu,\sigma^2)$](02_一维随机变量及其分布.md#normal) | $f(x)=\dfrac1{\sigma\sqrt{2\pi}}\exp\left[-\dfrac{(x-\mu)^2}{2\sigma^2}\right],\quad x\in\mathbb R$ | $\mu$ | $\sigma^2$ | 第二参数为方差，$\sigma>0$ |

## 4. 随机变量数字特征

| 概念 | 条目 | 公式 | 条件 / 说明 |
| --- | --- | --- | --- |
| 数学期望 | 定义 | $\mathbb{E}[X]=\displaystyle\int_{-\infty}^{+\infty}x\,\mathrm dF(x)=\int_{-\infty}^{+\infty}xf(x)\,\mathrm dx$ | 用分布函数或密度积分 |
| | 线性性 | $\mathbb{E}\left[\sum_{i=1}^{n}X_i\right]=\sum_{i=1}^{n}\mathbb{E}[X_i]$ | **无任何限制，普适** |
| | 独立之积 | $\mathbb{E}\left[\prod_{k=1}^{n}X_k\right]=\prod_{k=1}^{n}\mathbb{E}[X_k]$ | $X_1,\ldots,X_n$ 相互独立 |
| | 随机向量函数 | $\mathbb{E}[\boldsymbol Y]=\displaystyle\int_{\mathbb R^m}\boldsymbol y\,\mathrm dF_{\boldsymbol Y}(\boldsymbol y)=\int_{\mathbb R^n}g(\boldsymbol x)\,\mathrm dF_{\boldsymbol X}(\boldsymbol x)$ | $\boldsymbol Y=g(\boldsymbol X)$；无需先求出 $\boldsymbol Y$ 的分布 |
| | 上式分成两类 | $\begin{cases}\displaystyle\sum_{\boldsymbol x}g(\boldsymbol x)P(\boldsymbol X=\boldsymbol x),&\boldsymbol X\text{ 为离散型},\\[2mm]\displaystyle\int_{\mathbb R^n}g(\boldsymbol x)f_{\boldsymbol X}(\boldsymbol x)\,\mathrm d\boldsymbol x,&\boldsymbol X\text{ 为连续型}.\end{cases}$ | 只需 $\boldsymbol X$ 的分布 |
| | 常数倍 | $\mathbb{E}[c\boldsymbol X]=c\mathbb{E}[\boldsymbol X]$ | $c$ 为常数 |
| 方差 | 定义 | $\sigma^2=\operatorname{Var}(X)\equiv \mathbb{E}\left[(X-\mu)^2\right],\qquad\sigma=\sqrt{\operatorname{Var}(X)}$ | $\mu=\mathbb{E}[X]$ |
| | 计算公式 | $\operatorname{Var}(X)=\mathbb{E}[X^2]-\left(\mathbb{E}[X]\right)^2=\mathbb{E}[X^2]-\mu^2$ | 由期望的线性性得 |
| | 平移与缩放 | $\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$ | $a,b$ 为常数 |
| | 独立线性组合 | $\operatorname{Var}\left(\sum_{i=1}^{n}c_iX_i\right)=\sum_{i=1}^{n}c_i^2\operatorname{Var}(X_i)$ | $X_1,\ldots,X_n$ 相互独立 |
| | 差的方差 | $\operatorname{Var}(X_1-X_2)=\operatorname{Var}(X_1)+\operatorname{Var}(X_2)$ | $X_1,X_2$ 相互独立 |
| | 样本均值 | $\operatorname{Var}(\overline X)=\operatorname{Var}\left(\dfrac1n\sum_{i=1}^{n}X_i\right)=\dfrac{\sigma^2}{n}$ | 各 $X_i$ 相互独立且 $\operatorname{Var}(X_i)=\sigma^2$ |
| 协方差 | 定义 | $\operatorname{Cov}(X,Y)=\mathbb{E}\left[(X-\mathbb{E}[X])(Y-\mathbb{E}[Y])\right]$ | |
| | 对称性 | $\operatorname{Cov}(X,Y)=\operatorname{Cov}(Y,X)$ | |
| | 转化为期望计算 | $\operatorname{Cov}(X,Y)=\mathbb{E}[XY]-\mathbb{E}[X]\mathbb{E}[Y]$ | 由期望的线性性得 |
| | 双线性（尺度） | $\operatorname{Cov}(aX+b,\ cY+d)=ac\operatorname{Cov}(X,Y)$ | $a,b,c,d$ 为常数 |
| | 双线性（一般） | $\operatorname{Cov}(aX+bY,\ cX+dY)=ac\operatorname{Var}(X)+(ad+bc)\operatorname{Cov}(X,Y)+bd\operatorname{Var}(Y)$ | 同上 |
| | 自协方差 | $\operatorname{Cov}(X,X)=\operatorname{Var}(X)$ | 上式的特例 |
| | 独立的情形 | $\operatorname{Cov}(X,Y)=0$ | $X,Y$ 相互独立；反之不成立 |
