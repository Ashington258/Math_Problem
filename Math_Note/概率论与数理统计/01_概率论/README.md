# 概率论

本节从事件出发建立概率模型，以一维及二维分布描述随机变量，再通过数字特征概括中心位置、离散程度与变量之间的联系。

- [随机事件与概率](./随机事件与概率.md#probability)：样本空间与事件运算、概率模型、条件概率、独立性、全概率与贝叶斯。
- [一维随机变量及其分布](./一维随机变量及其分布.md#1-随机变量)：随机变量与分布函数、分布律、概率密度与常见分布。
- [二维随机变量及其分布](./二维随机变量及其分布.md#joint-cdf)：联合分布、边缘分布、条件分布、独立性与二维正态分布。
- [随机变量的数字特征](./随机变量的数字特征.md#numerical-characteristics)：期望、方差、协方差与相关系数、线性组合、矩与常用公式速查、条件期望与全方差、常见分布及概率不等式。

核心关系：

$$
F_{X,Y}(x,y)=P(X\le x,Y\le y),
\qquad
f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy,
\qquad
f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)} .
$$

三条主线层层递进：事件运算给出概率的计算规则；一维分布把概率换成数轴上的分布函数，离散情形用求和、连续情形用积分；二维分布把分布函数搬到平面上，对另一个变量积分消元得到边缘密度，再除以边缘密度做归一化得到条件密度。

数字特征以概率为权重对分布进行求和或积分。期望与方差概括位置和尺度，协方差与相关系数描述线性联系，条件期望与全方差连接条件分布与总体特征。
