# 概率论与数理统计

本区收录随机性与数据的数学：从概率的公理化基础出发，经随机变量、数字特征与极限定理，走向以数据反推规律的数理统计。

## 定位

本区与 [代数学](../代数学/README.md)、[分析学](../分析学/README.md) 并列，是独立的一级分支，不是二者的子集。

- 概率论的严格化依赖分析（测度、积分、特征函数）；
- 数理统计依赖概率论与线性代数（协方差矩阵、最小二乘、多元统计）。

因此本区**借用**代数与分析的结论，但研究的是确定性结构之外的对象：随机性，以及由数据反推规律。

## 文档规范

- 每篇笔记使用一个一级标题，标题与文件名表达同一主题（不要出现"总结""笔记"等冗余后缀）。
- 内容按"定义 → 核心结论 → 推导或证明 → 例子 → 总结"组织；不适用的部分可省略。
- 公式统一使用 KaTeX：行内公式用 `$...$`，独立公式用 `$$...$$`。**不要**使用 `\( \)` 与 `\[ \]` 定界。
- 章节标题用阿拉伯数字编号：一级用 `## 1. 标题`，二级用 `### 1.1 标题`。
- 表格分隔行写作 `| --- | --- |`；表格内绝对值用 `\lvert a\rvert`，范数用 `\lVert x\rVert`。
- 新概念首次出现时给出中文名、英文名和推荐数学记号。
- 跨文件引用用带显式锚点的相对链接；每个节的 README 末尾保留一行"返回上级索引"。
- 文件末尾恰好保留一个换行，不留空白行。
