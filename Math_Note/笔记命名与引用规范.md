# 笔记命名与引用规范

本规范用于新增笔记及本次微积分相关笔记的整理；历史专题在后续修改时逐步对齐。

## 1. 文件名与标题

- 章节目录沿用 `NN_主题`，如 `02_多元微分学`；目录入口统一为 `README.md`。
- 正文用稳定、简短的主题名，不把全部知识点写进文件名，例如 `微分与局部线性映射.md`、`多元微分学详解.md`、`多元微分学速查.md`、`多元积分学速查.md`。
- 正文一级标题与文件名主干一致。说明范围的长副标题放在一级标题下面，既保留内容信息，也使链接名称稳定。
- 同一主题的“速查”只保留公式、条件和索引；“详解”负责推导、图像、物理解释和反例；习题放在现有 `例题/` 下。
- 改名时同步更新全部库内引用。旧 PDF 是独立导出物，未经重新生成不能仅改名假装与新正文一致。

## 2. 引用方式

- 库内文件统一用标准 Markdown 相对链接，路径分隔符用 `/`；例如 `[多元微分学详解](多元微分学详解.md)`。
- 链接文字通常用目标文件的主题名；需要引用具体内容时，可用“详解第 6 节”等说明，并仍链接到目标文件。
- 目录链接指向该目录的 `README.md`。历史目录若尚无索引，可临时直接链接目录。
- 不新增机器绝对路径、`file://` 链接或只靠同名匹配的 `[[双链]]`。文件名含空格或括号时，用尖括号包裹目标，例如 `[文章](<相对路径/文章 (附录).md>)`。
- 新增跨文件引用优先链接整篇笔记，避免改动标题导致片段锚点失效；已有片段引用保留时，须在目标渲染器中核对。
- 公式速查链接到详解；详解链接到前置与后续；章节 README 作为总入口。每个概念的推导有明确的主要归属，其他笔记以链接衔接。

## 3. 插图及生成代码

- 新增插图集中在笔记所在目录的 `image/主题名/` 下，避免不同文章的 `fig-01` 相互混淆。
- 图片使用 `fig-NN-英文内容名.png`，配套矢量文件使用同一主干的 `.pdf`、`.svg`。
- 正文嵌入 PNG；图下说明函数、参数、面板含义、方向与尺度。图号按正文首次出现顺序编号。
- 同目录保存 `make_figures.py`、所需绘图样式及 `README.md`，记录运行命令、依赖、图像单位和输出规格。
- 新增示意图应可由代码完整重现；有颜色编码时同时用线型、标记、箭头或文字区分含义。

## 5. 修改后的检查

1. 从章节 README 能进入正文、速查和配图目录。
2. 搜索旧文件名，确认活动引用已更新；迁移说明中的旧名称可保留。
3. 检查 Markdown 链接与嵌入图片的目标存在，并核对正文图号与文件号。
4. 运行绘图脚本，查看彩图与灰度预览，核对箭头、图例、轴标签和导出尺寸。
