# 矩阵与运算

本节把矩阵当作线性映射在给定基下的表示来研究：先给出定义与乘法规则，再整理逆矩阵、初等变换与分块技巧。

- [矩阵](./矩阵.md)：定义、运算律、逆矩阵、初等变换、四个基本子空间与特殊矩阵速查。
- [分块矩阵](./分块矩阵.md)：分块运算、Schur 补、Kronecker 积与常见应用。

核心关系：

$$
T(x)=Ax,
\qquad
(AB)_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj},
\qquad
A\text{ 可逆}\iff \lvert A\rvert\neq 0\iff \operatorname{rank}(A)=n .
$$

矩阵是后续所有章节的共同语言：[行列式](../05_行列式/行列式.md) 是方阵的标量不变量，[线性方程组](../03_线性方程组与基本子空间/README.md) 是它的原像问题，[特征值与谱](../07_特征值与谱/README.md) 研究它在换基下的相似标准形。
