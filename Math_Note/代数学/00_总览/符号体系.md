# 符号体系

本文是代数学全章的**记号总表**。§1 给出各篇共同遵循的统一记法规范；§2–§6 逐条还原四个基本子空间手绘图（$A:\mathbb R^n\to\mathbb R^m$ 一图）中的记号；§7 汇总只在单篇出现的局部记号。设 $A\in\mathbb F^{m\times n}$，$\mathbb F$ 取 $\mathbb R$ 或 $\mathbb C$，$r=\operatorname{rank}(A)$。

## 1. 全书统一记法规范

### 1.1 数域与矩阵空间

| 记号 | 含义 | 使用场合 |
| --- | --- | --- |
| $\mathbb F$ | 任意域 | 抽象命题（对 $\mathbb R$ 与 $\mathbb C$ 都成立） |
| $\mathbb R$、$\mathbb C$ | 实数域、复数域 | 具体计算、几何、实对称与正交矩阵 |
| $\mathbb Z$、$\mathbb N$ | 整数、自然数 | 指标集与计数 |
| $\mathbb F^{m\times n}$ | $m\times n$ 矩阵空间 | 矩阵篇、线性映射篇 |
| $\mathbb S^n$ | $n$ 阶实对称矩阵空间 | 对称矩阵篇 |
| $\mathbb K^n$ | $n$ 阶实反对称矩阵空间 | 对称矩阵篇 |

**规则。** 抽象命题用 $\mathbb F$，具体实/复情形用 $\mathbb R$ 或 $\mathbb C$；两者并存是**分工**而非不一致。数域不写花括号：写 $\mathbb F$、$\mathbb R$，不写 $\mathbb{F}$。

### 1.2 矩阵、向量与零元

| 记号 | 含义 | 说明 |
| --- | --- | --- |
| $A,B,C,D,M$ | 矩阵 | 斜体大写 |
| $I$、$I_n$、$I_r$ | 单位矩阵 | 需强调阶数时带下标 |
| $O$ | 零矩阵 | 分块矩阵中与零标量区分 |
| $u,v,x,y$ | 向量 | **一律斜体**，不加粗 |
| $\mathbf{0}$ | 零向量 | 与零标量 $0$ 区分，保留粗体 |
| $\mathbf 1$ | 全 $1$ 向量 | 保留粗体 |
| $a_{ij}$、$A_{ij}$ | 元素 / 分块 | 元素用小写双下标，分块用大写双下标 |
| $x_p$ | 非齐次特解 | 落在 $\operatorname{Row}(A)$ 内时唯一 |
| $x_{\text{null}}$ | 齐次部分的自由量 | 下标用 `\text` |
| $S_b$ | 解集 $\{x:Ax=b\}$ | 仿射空间，不必是线性空间 |
| $T$、$T_A$ | 线性映射 | 矩阵 $A$ 对应的映射记 $T_A$ |

**向量的字体。** 抽象向量与 $\mathbb R^n$ 中的坐标向量**不靠字体区分**，靠上下文与下标（$x=(x_1,\dots,x_n)$）区分。只有零向量与全 $1$ 向量保留粗体，因为它们常与标量 $0$、$1$ 同处一式中。

### 1.3 子空间与算子

| 记号 | 含义 | 备注 |
| --- | --- | --- |
| $\operatorname{Col}(A)$ | 列空间 | 与 $\operatorname{Im}(A)$ 同义；具体矩阵用 $\operatorname{Col}$，一般映射用 $\operatorname{Im}$ |
| $\operatorname{Row}(A)$ | 行空间 | 等于 $\operatorname{Col}(A^{\mathsf T})$ |
| $\ker(A)$ | 零空间（核） | LaTeX 内置命令，不加 `\operatorname` |
| $\operatorname{Im}(T)$ | 像（值域） | 用于一般映射 |
| $\operatorname{rank}(A)$ | 秩 | — |
| $\dim\ker(A)$ | 零化度 | 不写 `nullity` |
| $\operatorname{tr}(A)$ | 迹 | — |
| $\operatorname{diag}(\dots)$ | 对角矩阵 | — |
| $\operatorname{span}\{\dots\}$ | 张成 | — |
| $\operatorname{sgn}(\sigma)$ | 置换符号 | 行列式篇 |
| $\operatorname{char}$、$\operatorname{spec}$ | 特征多项式、谱 | 谱理论篇 |
| $\det$、$\dim$、$\ker$ | 行列式、维数、核 | LaTeX 内置，直接使用 |

自造算子名一律写 `\operatorname{...}` 且**首字母大写**（`Col`、`Row`、`Im`、`rank`、`tr`、`diag`、`span`、`sgn`）。

**括号规则。** 单字母参数可省可不省，但**同一篇内保持一致**；复合参数必须加括号。

| 情形 | 写法 | 反例 |
| --- | --- | --- |
| 参数是单个矩阵 | $\ker(A)$、$\operatorname{rank}(A)$、$\operatorname{tr}(A)$ | $\operatorname{rank}A+B$ 有歧义 |
| 参数是单个映射 | $\ker(T)$、$\operatorname{Im}(T)$ | $\ker T+S$ 有歧义 |
| 参数是复合式 | $\ker(AB)$、$\operatorname{tr}(A+B)$ | $\ker AB$ 有歧义 |
| 参数带转置或伴随 | $\operatorname{rank}(A^{\mathsf T})$、$\ker(A^{*})$ | **不写** $\operatorname{rank}(A)^{\mathsf T}$ |

最后一行是头号易错点：上标属于**参数**而不是算子，括号必须包住上标。

### 1.4 定界符、绝对值与范数

| 记号 | 含义 | 备注 |
| --- | --- | --- |
| $\lvert a\rvert$ | 绝对值、模 | 表格中不用裸竖线，会被当成列分隔 |
| $\lvert A\rvert$ | 行列式（矩阵作元素时） | 与 $\det A$ 的分工见下 |
| $\lVert u\rVert$、$\lVert\cdot\rVert_2$、$\lVert\cdot\rVert_F$ | 范数 | 不用竖线符号 |
| $\langle u,v\rangle$ | 内积 | — |
| `\left\lvert…\right\rvert` | 显式矩阵的行列式 | 自适应定界 |

**行列式规则。** 理论叙述、算子层与推导写 $\det A$；把矩阵当作**单个元素**、或需要与绝对值的竖线形式统一时写 $\lvert A\rvert$（显式写出的矩阵用 `vmatrix` 或 `\left\lvert…\right\rvert`）。两者都是标准写法，**同一篇内保持主导写法一致**即可；本库现状以 $\lvert A\rvert$ 为主。

矩阵环境：数值与工程味强的场景用 `bmatrix`，纯数学与分块用 `pmatrix`，行列式用 `vmatrix`；三者混用不算不一致。

### 1.5 关系与逻辑

| 语义 | 统一写法 | 说明 |
| --- | --- | --- |
| 当且仅当 | $\iff$ | — |
| 蕴含 | $\implies$ | 少用 $\Rightarrow$ |
| 小于等于、大于等于、不等于 | $\leq$、$\geq$、$\neq$ | 一律长写 |
| 相似 | $A\sim B$ | 即 $B=P^{-1}AP$ |
| 合同 | 纯文字「$A$ 与 $B$ 合同」 | 符号不统一，故不引入符号 |
| 等价 | 纯文字「$A$ 与 $B$ 等价」 | 即 $B=PAQ$ |
| 正交、正交补 | $u\perp v$、$W^\perp$ | — |
| 含于 | $\subseteq$ | 真子集另加文字说明 |
| 映射与元素 | $T:V\to W$、$x\mapsto Tx$ | 长箭头只在需要拉开间距的展示式中用 |
| 空集 | $\varnothing$ | 不用 $\emptyset$ |

### 1.6 字体、证毕与排版

| 记号 | 用途 | 说明 |
| --- | --- | --- |
| $A^{\mathsf T}$ | 转置 | 直立 T，**不写** $A^T$、$A^\top$ |
| $A^{H}$ | 共轭转置 | 不用 `\dagger` |
| $A^{*}$ | 伴随矩阵 | 与共轭转置区分 |
| $\overline{\lambda}$、$\overline{A}$ | 标量共轭、矩阵共轭 | 不用 `\bar` |
| $\tilde{v}$ | 「去掉某个分量后」的临时记号 | 单篇局部 |
| $\square$ | 证毕 | 全书唯一，不用 $\blacksquare$ |
| $\boxed{\dots}$ | 判据框 | 本库特色，置于每节收束之前 |
| $\underbrace{\dots}_{}$ | 结构标注 | — |
| $\oplus$、$\otimes$ | 直和、张量积 | 大型直和才用 $\bigoplus$ |

**点列规则。** 逗号分隔的列举用 $\dots$；加法、乘法等算子之间的省略用 $\cdots$；矩阵的行内省略也一律用 $\cdots$。不再使用 `\ldots`。

### 1.7 禁用写法

| 禁用 | 正确 | 原因 |
| --- | --- | --- |
| $C(A)$、$R(A)$ | $\operatorname{Col}(A)$、$\operatorname{Row}(A)$ | 非标准缩写 |
| $N(A)$、$\operatorname{Nul}(A)$ | $\ker(A)$ | 非标准缩写 |
| $r(A)$ | $\operatorname{rank}(A)$ | 与标量函数混淆 |
| $\mathrm{nullity}(A)$ | $\dim\ker(A)$ | 同上 |
| $A^T$、$A^\top$ | $A^{\mathsf T}$ | 直立 T 更清晰 |
| $A^{\dagger}$ | $A^{H}$ 或 $A^{*}$ | 符号歧义 |
| $\emptyset$ | $\varnothing$ | 全书统一 |
| $\blacksquare$ | $\square$ | 全书统一 |
| `\( \)`、`\[ \]` | `$…$`、`$$…$$` | KaTeX 与 MPE 的定界 |

## 2. 映射层

图顶端写的是 $A:\mathbb R^n\to\mathbb R^m$（手写作 `IR^n → IR^m`），以及 $A_{m\times n}x=B$。

| 图中记号 | 统一记号 | 说明 |
| --- | --- | --- |
| $A:\mathbb R^n\to\mathbb R^m$ | $T_A:\mathbb F^n\to\mathbb F^m$ | 定义域 domain 为 $\mathbb F^n$，目标空间 codomain 为 $\mathbb F^m$ |
| `Input ∈ R^n` | $x\in\mathbb F^n$ | 被映射的输入向量 |
| `Output ∈ R^m` | $b\in\mathbb F^m$ | 映射结果 |
| $Ax=B$ | $Ax=b$ | 右端统一用小写 $b$，大写 $B$ 留给矩阵 |
| 「映射」箭头 | $T_A(x)=Ax$ | 箭头表示 $A$ 对向量的作用 |

## 3. 四个基本子空间

图中把输入、输出空间并排画成两串：

```text
Σdim = n ← Nul(A) ← Row(A) → Col(A) → Nul(A^T) → Σdim = m
```

| 图中记号 | 统一记号 | 所在空间 | 维数 | 图中语义 |
| --- | --- | --- | --- | --- |
| `Nul(A)` | $\ker(A)$ | $\mathbb F^n$ | $n-r$ | 输入落在此空间中，则输出为 $0$ |
| `Row(A)` | $\operatorname{Row}(A)=\operatorname{Col}(A^{\mathsf T})$ | $\mathbb F^n$ | $r$ | 输入落在此空间中，输出铺满 $\operatorname{Col}(A)$ |
| `Col(A)` | $\operatorname{Col}(A)=\operatorname{Im}(A)$ | $\mathbb F^m$ | $r$ | 实际可达的输出（值域），有解当且仅当 $b$ 在此 |
| `Nul(A^T)` | $\ker(A^{\mathsf T})=\operatorname{Col}(A)^\perp$ | $\mathbb F^m$ | $m-r$ | 无法到达的输出方向，$b$ 带此分量则无解 |
| `Σdim = n` | $\dim\ker(A)+\dim\operatorname{Row}(A)=n$ | — | — | 输入空间被这两组基拼满 |
| `Σdim = m` | $\dim\operatorname{Col}(A)+\dim\ker(A^{\mathsf T})=m$ | — | — | 输出空间被这两组基拼满 |

图中未写出的等价形式是 $\operatorname{Row}(A)=\ker(A)^\perp$ 与 $\ker(A^{\mathsf T})=\operatorname{Col}(A)^\perp$，于是

$$
\mathbb F^n=\ker(A)\oplus\operatorname{Row}(A),\qquad
\mathbb F^m=\operatorname{Col}(A)\oplus\ker(A^{\mathsf T}).
$$

图中的「×」与红圈属于强调标注，不是数学记号。

## 4. 红箭头：$A$ 在 Row 与 Col 之间的作用

图中用红色箭头把 `Row(A)` 连到 `Col(A)`，旁注「A 映射」，意思是限制映射

$$
A|_{\operatorname{Row}(A)}:\operatorname{Row}(A)\longrightarrow\operatorname{Col}(A)
$$

为线性同构：单射（核为 $\{0\}$）、满射（两侧维数同为 $r$），故一一对应。这正是下文「$x_r$ 唯一」的来源。

## 5. 解的结构

图下半部分写道：若 $b\in\operatorname{Col}(A)$ 则有解，此时解为 $x=x_r+x_{\text{null}}$。

| 图中记号 | 统一记号 | 含义 |
| --- | --- | --- |
| $b\in\operatorname{Col}(A)$ | $S_b\neq\varnothing$ | 方程可解的充要条件 |
| $x_r$ | $x_p$，且要求 $x_p\in\operatorname{Row}(A)$ | 非齐次特解，落在 $\operatorname{Row}(A)$ 中时唯一 |
| `x_null` | $x_{\text{null}}\in\ker(A)$ | 齐次部分的自由量 |
| $x=x_r+x_{\text{null}}$ | $S_b=x_p+\ker(A)$ | 全部解 = 一个特解 + 整个零空间 |

由图可得

$$
b\in\operatorname{Col}(A)\iff S_b\neq\varnothing,\qquad
S_b=x_r+\ker(A),\quad x_r\in\operatorname{Row}(A)\ \text{唯一}.
$$

图中「注意唯一性」的准确含义是：**特解本身不唯一，但落在 $\operatorname{Row}(A)$ 内的那个特解唯一**。

## 6. 手写简写的统一

图中出现的简写不进入笔记正文，一律按仓库记法改写：

| 图中写法 | 统一为 |
| --- | --- |
| `Nul(A)`、`N(A)` | $\ker(A)$ |
| `Nul(A^T)` | $\ker(A^{\mathsf T})$ |
| `C(A)`、`R(A)` | $\operatorname{Col}(A)$ |
| `Row(A)` | $\operatorname{Row}(A)$ |
| `A^T` | $A^{\mathsf T}$ |
| `Σdim` | $\dim$ 的显式和式 |
| `x_r`、`x_null` | $x_p$、$x_{\text{null}}$ |
| `Ax=B` | $Ax=b$ |
