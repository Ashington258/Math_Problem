# 总览

本节回答“线性代数研究什么，以及各主题如何连接”。

主线按**结构顺序**（目录顺序）叙述，即“对象 → 表示与运算 → 问题 → 不变量 → 几何 → 谱 → 二次 → 类型清单”；具体章节顺序见 [代数学索引](../README.md)。
