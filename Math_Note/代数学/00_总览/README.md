# 总览

本节回答“线性代数研究什么，以及各主题如何连接”。

- [线性代数知识主线](./线性代数知识主线.md)：唯一的知识地图。先给全篇路线图，再以“线性映射”为统一视角，最后逐章说明每层解决了什么、又留下什么。
- [线性方程组的六种语言](./线性方程组的六种语言.md)：横切专题。同一个 $Ax=b$ 在消元、行列式、秩、向量组、线性空间、内积六种语言下各自的判据、等价描述与对照表；适合读过 02–06 章后回看。
- [符号体系](./符号体系.md)：从手绘关系图中提取的记号清单，以及它们与仓库统一记法的对照。

主线按**结构顺序**（目录顺序）叙述，即“对象 → 表示与运算 → 问题 → 不变量 → 几何 → 谱 → 二次 → 特殊清单（矩阵与行列式）”；具体章节顺序见 [代数学索引](../README.md)。
