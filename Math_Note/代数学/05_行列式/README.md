# 行列式

本节整理方阵的行列式，分结论层与推导层两篇，互为姊妹篇。

- [行列式](./行列式.md)：结论层。定义、基本性质、展开定理、与矩阵运算的关系、特殊公式与几何意义。
- [行列式的公理化推导](./行列式的公理化推导.md)：推导层。从三条公理推出全部结论，含唯一性、乘积法则与溯源表。

核心关系：

$$
\lvert AB\rvert=\lvert A\rvert\lvert B\rvert,
\qquad
\lvert A\rvert\neq 0\iff A\text{ 可逆},
\qquad
\lvert A\rvert=\prod_{i=1}^{n}\lambda_i .
$$

行列式与 [秩](../04_秩/README.md) 是同一条主轴上的两个不变量：秩是“像空间的维数”，行列式是“有向体积的缩放因子”，前者刻画全类型矩阵，后者只对方阵有定义。
