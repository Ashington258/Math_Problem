# 秩

秩刻画线性映射像空间的维数，也是行空间与列空间的公共维数。

- [秩的常见不等式](./秩的常见不等式.md)：和、乘积、拼接矩阵与伴随矩阵的秩估计。

核心关系：

$$
\operatorname{rank}(A)=\dim\operatorname{Col}(A)=\dim\operatorname{Row}(A),
\qquad
\operatorname{rank}(A)+\dim\ker(A)=n.
$$

秩是矩阵在等价关系下的完全不变量，也是 [行列式](../05_行列式/行列式.md) 之外唯一与方阵是否可逆直接挂钩的量；四个基本子空间的维数全部由它和 $m,n$ 决定（见 [线性方程组与基本子空间](../03_线性方程组与基本子空间/README.md)）。
