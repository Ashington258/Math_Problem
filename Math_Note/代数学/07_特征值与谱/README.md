# 特征值与谱

本节研究方阵在相似变换下的谱结构：相似不变量、可对角化条件，以及实对称矩阵的正交相似对角化。

- [相似矩阵](./相似矩阵.md)：定义、基本性质与相似不变量。
- [相似对角化](./相似对角化.md)：可对角化条件、判别方法与构造。
- [特征分解](./特征分解.md)：特征向量基下的矩阵分解。
- [实对称矩阵的正交相似对角化](./实对称矩阵的正交相似对角化.md)：实谱定理及其推论。

逻辑关系：实对称矩阵一定可以正交相似对角化；一般方阵只有在具有一组特征向量基时才可以相似对角化。

$$
A=P\Lambda P^{-1}
\quad\text{（相似对角化）},
\qquad
A=Q\Lambda Q^{\mathsf T}
\quad\text{（正交相似对角化）}.
$$

对二次型做换元 $x=Py$ 时，矩阵作的是合同变换而非相似变换，详见 [二次型与合同](../08_二次型与合同/README.md)。对称矩阵本身的结构性质见 [特殊矩阵](../09_特殊矩阵/对称矩阵.md)。
