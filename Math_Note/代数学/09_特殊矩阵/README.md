# 特殊矩阵

本节按结构特征整理矩阵。相似矩阵已归入 [特征值与谱](../07_特征值与谱/README.md)，因为“相似”是矩阵之间的关系，不是单个矩阵的结构类型；分块矩阵归入 [矩阵与运算](../02_矩阵与运算/分块矩阵.md)，因为它是运算技巧。

- [对称矩阵](./对称矩阵.md)：自伴随本质、谱定理、定号判定、乘积与合同/相似行为、常见来源。
- [正交矩阵](./正交矩阵.md)：内积不变性、谱性质与几何意义。
- [秩为 1 的矩阵](./秩为1.md)：外积表示、特征结构、范数与应用。

核心关系：

$$
A^{\mathsf T}=A\ \text{（实对称）}
\Longrightarrow
A=Q\Lambda Q^{\mathsf T},
\qquad
Q^{\mathsf T}Q=I
\Longrightarrow
\lvert Q\rvert=\pm 1,
\qquad
\operatorname{rank}(A)\le 1\iff A=uv^{\mathsf T}.
$$

三类矩阵互相咬合：正交矩阵给出保持对称性的那类相似变换，对称矩阵给出可对角化的那类，秩 1 矩阵给出可分解的最小单元。
