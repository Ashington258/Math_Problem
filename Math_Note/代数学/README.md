# 代数与线性代数索引

本目录以“空间与映射”为主线组织线性代数笔记，顺序为：**建立对象 → 给出表示与运算 → 提出问题 → 提取不变量 → 补上几何结构 → 分解 → 分类**。行列式紧接秩之后（都是不变量），内积与正交化排在谱分解之前（谱定理依赖正交性），最后才是相似、合同与特殊矩阵。

## 学习路径

1. [总览](./00_总览/README.md)：建立线性代数的统一视角与知识地图。
2. [线性空间与线性映射](./01_线性空间与线性映射/README.md)：线性结构、线性相关、基与维数，以及函数空间等非 $\mathbb R^n$ 的例子。
3. [矩阵与运算](./02_矩阵与运算/README.md)：矩阵作为线性映射的表示，以及乘法、逆、初等变换与分块技巧。
4. [线性方程组与基本子空间](./03_线性方程组与基本子空间/README.md)：$Ax=b$ 的可解性与解集结构，四个基本子空间及其正交分解。
5. [秩](./04_秩/README.md)：秩作为线性映射的不变量，其性质与不等式。
6. [行列式](./05_行列式/README.md)：方阵的行列式，结论层与公理化推导层两篇。
7. [内积与正交化](./06_内积与正交化/README.md)：双线性形式、内积、Gram–Schmidt 正交化与三维叉积技巧。
8. [特征值与谱](./07_特征值与谱/README.md)：相似、特征分解、相似对角化与实对称谱定理。
9. [二次型与合同](./08_二次型与合同/README.md)：合同变换、惯性指数与规范型。
10. [特殊矩阵](./09_特殊矩阵/README.md)：按结构特征整理的对称、正交与秩 1 矩阵。

主线依赖关系：

$$
\text{线性空间}
\to \text{矩阵}
\to \text{方程组}
\to \text{秩} \to \text{行列式}
\to \text{内积与正交化}
\to \text{谱分解} \to \text{合同与二次型}
\to \text{特殊矩阵}.
$$

## 记号约定

设 $A\in\mathbb F^{m\times n}$，其中 $\mathbb F$ 通常为 $\mathbb R$ 或 $\mathbb C$。

| 对象 | 推荐记号 | 所在空间 |
| --- | --- | --- |
| 列空间（像） | $\operatorname{Col}(A)=\operatorname{Im}(A)$ | $\mathbb F^m$ |
| 行空间 | $\operatorname{Row}(A)=\operatorname{Col}(A^{\mathsf T})$ | $\mathbb F^n$ |
| 零空间（核） | $\ker(A)$ | $\mathbb F^n$ |
| 左零空间 | $\ker(A^{\mathsf T})$ | $\mathbb F^m$ |
| 秩 | $\operatorname{rank}(A)$ | 非负整数 |
| 零化度 | $\dim\ker(A)$ | 非负整数 |
| 转置 / 共轭转置 | $A^{\mathsf T}$ / $A^{H}$ | 同型 |
| 伴随矩阵 | $A^{*}$ | 同型方阵 |
| 迹 / 行列式 | $\operatorname{tr}A$ / $\lvert A\rvert$ | 标量 |
| 范数 / 绝对值 | $\lVert x\rVert$ / $\lvert a\rvert$ | 标量 |

正文优先使用 $\operatorname{Col}$、$\operatorname{Row}$、$\ker$、$\operatorname{rank}$ 和 $\operatorname{tr}$。**不再使用** $C(A)$、$N(A)$、$R(A)$、$r(A)$、$\mathrm{nullity}(A)$、$\mathrm{Col}(A)$ 这类简写。非齐次方程 $Ax=b$ 的所有解称为“解集”，记作 $S_b=x_p+\ker(A)$；它非空时通常是仿射空间，不一定是线性空间。

## 文档规范

- 每篇笔记使用一个一级标题，标题与文件名表达同一主题（不要出现“总结”“笔记”等冗余后缀）。
- 内容按“定义 → 核心结论 → 推导或证明 → 例子 → 总结”组织；不适用的部分可省略。
- 公式统一使用 KaTeX：行内公式用 `$...$`，独立公式用 `$$...$$`。**不要**使用 `\( \)` 与 `\[ \]` 定界。
- 章节标题用阿拉伯数字编号：一级用 `## 1. 标题`，二级用 `### 1.1 标题`。不要用 `## **1. 标题**` 加粗伪标题，也不要用 `一、二、` 中文序号。
- 表格分隔行写作 `| --- | --- |`；表格内绝对值用 `\lvert a\rvert`，范数用 `\lVert x\rVert`（裸 `|` 会被解析为列分隔）。
- 新概念首次出现时给出中文名、英文名和推荐数学记号。
- 区分“集合相等”“线性同构”和“维数相等”，并注明各子空间所在的环境空间。
- 跨文件引用用带显式锚点的相对链接；每个节的 README 末尾保留一行“返回上级索引”。
- 文件末尾恰好保留一个换行，不留空白行。
