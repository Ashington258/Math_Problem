- [相似矩阵](./01_特征值与对角化/02_相似矩阵.md)：相似的定义、基本性质与相似不变量。

- [谱分解](./01_特征值与对角化/04_谱分解.md)：正交特征基表示、一维投影形式与按特征子空间的投影形式。

- [特征值与对角化例题](./01_特征值与对角化/例题/例题.md)：四个 $3\times3$ 矩阵的完整求解：特征值、特征子空间、可对角化判定与 $P$、$\Lambda$ 的构造。
