# 矩阵分解索引

本目录以“分解”为主线组织笔记：把一个矩阵写成若干结构简单因子的乘积，用它读取矩阵的**特征结构**、线性映射的**子空间结构**，以及线性方程组的**数值求解路径**。

## 学习路径

1. [总览](./00_总览/README.md)：本章的地图与脉络，以及三条主线的统一视角与速查表。
2. [特征结构与标准形](./01_特征结构与标准形/README.md)：特征值与特征子空间、相似对角化、谱分解、Jordan 标准形与 Schur 分解。
3. [子空间与奇异值分解](./02_子空间与奇异值分解/README.md)：四大基本子空间、奇异值与奇异向量、SVD 及其推论。
4. [数值分解与方程求解](./03_数值分解与方程求解/README.md)：高斯消元、LU / PLU、QR、Cholesky 与分解方法的用途对照。

三条主线依次回答不同的问题：

$$
\text{特征结构与标准形}
\;\longrightarrow\;
\text{子空间与奇异值分解}
\;\longrightarrow\;
\text{数值分解与方程求解}.
$$

前者描述方阵自身的结构，中间者描述线性映射的定义域与值域，后者把这些结构变成可执行的算法。

## 与其它章节的接口

- 特征值与特征向量的定义、相似与相似不变量见 [线性空间与线性映射](../01_线性空间与线性映射/README.md) 与 [矩阵与运算](../02_矩阵与运算/README.md)；
- 四个基本子空间的定义层与解集结构留在 [线性方程组与基本子空间](../03_线性方程组与基本子空间/README.md)；
- 正交化的合法性来自 [内积与正交化](../06_内积与正交化/README.md)；
- 分解结果落到二次型与合同，见 [二次型与合同](../08_二次型与合同/README.md)；
- 对称、正交、秩 1 等具体结构见 [特殊矩阵](../09_特殊矩阵/README.md)。

## 记号约定

本工作空间沿用 [符号体系](../00_总览/符号体系.md) 第 1 节的规定：转置写 $A^{\mathsf T}$，共轭转置写 $A^{H}$，伴随矩阵写 $A^{*}$，共轭写 $\overline{\lambda}$；算子统一带括号，写成 $\ker(A)$、$\operatorname{rank}(A)$、$\operatorname{tr}(A)$、$\operatorname{Col}(A)$、$\operatorname{Row}(A)$。奇异值记 $\sigma_i$，右奇异向量记 $v_i$，左奇异向量记 $u_i$。

## 文档规范

- 每篇笔记使用一个一级标题，标题与文件名表达同一主题（不要出现“总结”“笔记”等冗余后缀）。
- 内容按“定义 → 核心结论 → 推导或证明 → 例子 → 总结”组织；不适用的部分可省略。
- 公式统一使用 KaTeX：行内公式用 `$...$`，独立公式用 `$$...$$`。**不要**使用 `\( \)` 与 `\[ \]` 定界。
- 章节标题用阿拉伯数字编号：一级用 `## 1. 标题`，二级用 `### 1.1 标题`。不要用 `## **1. 标题**` 加粗伪标题，也不要用 `一、二、` 中文序号。
- 表格分隔行写作 `| --- | --- |`；表格内绝对值用 `\lvert a\rvert`，范数用 `\lVert x\rVert`（裸 `|` 会被解析为列分隔）。
- 跨文件引用用带显式锚点的相对链接；每章 README 末尾保留一行“返回矩阵分解索引”。
- 文件末尾恰好保留一个换行，不留空白行。
