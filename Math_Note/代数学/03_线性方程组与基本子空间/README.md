# 线性方程组与基本子空间

对于 $A\in\mathbb F^{m\times n}$，方程 $Ax=b$ 是求线性映射 $T_A:\mathbb F^n\to\mathbb F^m$ 的原像。列空间决定是否有解，零空间决定解的自由度。

把同一个问题放在行列式、秩、向量组、内积等各套语言下并排对照的专题，见 [线性方程组的六种语言](../00_总览/线性方程组的六种语言.md)。

本节正文按“定义 → 求解 → 运算”分工，建议按下列顺序阅读：

- [列空间、零空间与解集](./列空间、零空间与解集.md)：**定义层**。三个基本对象的确切定义、规范记法与求法，以及解集的几何结构。
- [线性方程组的判定与求解](./线性方程组的判定与求解.md)：**求解层**。三步判据、求解流水线与例题集。
- [矩阵左右乘对四个基本子空间的影响](./矩阵左右乘对四个基本子空间的影响.md)：**运算层**。一般乘法与可逆乘法下四个子空间如何变化。
- [矩阵乘积为零时的子空间关系](./矩阵乘积为零时的子空间关系.md)：**运算层**。由 $AB=0$ 推出 $\operatorname{Col}(B)\subseteq\ker(A)$ 及其等价表述。

四个基本子空间与正交分解归入 [矩阵分解·四大基本子空间](../07_矩阵分解/02_子空间与奇异值分解/01_映射的子空间结构/01_四大基本子空间.md)，那一章另用奇异值分解把四组正交基写成矩阵形式；本章保留解集本身的几何（仿射结构、最小范数解与最小二乘，见 [列空间、零空间与解集](./列空间、零空间与解集.md) §5）。

核心关系：

$$
Ax=b\text{ 有解}\iff b\in\operatorname{Col}(A),
\qquad
S_b=x_p+\ker(A),
\qquad
\operatorname{rank}(A)+\dim\ker(A)=n .
$$

解集的唯一分解 $x=x_r+x_{\text{null}}$（$x_r\in\operatorname{Row}(A)$ 唯一、$x_{\text{null}}\in\ker(A)$）见 [列空间、零空间与解集](./列空间、零空间与解集.md) §5 与 [四大基本子空间](../07_矩阵分解/02_子空间与奇异值分解/01_映射的子空间结构/01_四大基本子空间.md) §2。
