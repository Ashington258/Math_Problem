# 二次型与合同

- [实对称矩阵的规范型](./实对称矩阵的规范型.md)：合同对角化、Sylvester 惯性定理及规范型。

对于二次型 $q(x)=x^{\mathsf T}Ax$，换元 $x=Py$ 导致矩阵作合同变换：

$$
q(Py)=y^{\mathsf T}(P^{\mathsf T}AP)y .
$$

合同与相似的区别：相似保持特征值，合同保持二次型的正定性。实对称矩阵可以同时用正交变换（既是相似也是合同）化为对角形，这就是 [特征值与谱](../07_特征值与谱/实对称矩阵的正交相似对角化.md) 与本节规范型的交汇点。
