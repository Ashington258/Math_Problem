# 线性空间与线性映射

本节建立线性代数的抽象对象。线性空间规定可以进行的运算，线性映射描述保持这些运算的结构变换。

- [线性空间定义和示例](./线性空间定义和示例.md)：八条公理、常见例子、反例与证明方法。
- [函数空间是线性空间](./函数空间是线性空间.md)：以 $\mathbb F^X$ 为例逐条验证八条公理，并推广到 $C[a,b]$、$L^2[a,b]$ 与多项式空间。

核心关系：

$$
\mathbf u+\mathbf v\in V,
\quad
\lambda\mathbf v\in V,
\qquad
T(\alpha\mathbf u+\beta\mathbf v)=\alpha T(\mathbf u)+\beta T(\mathbf v).
$$

后续可补充：子空间、线性相关性、基与维数、坐标与换基、线性映射的矩阵表示。
