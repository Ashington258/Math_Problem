# 线性空间与线性映射

本节建立线性代数的抽象对象。线性空间规定可以进行的运算，线性映射描述保持这些运算的结构变换。

- [线性空间定义和示例](./线性空间定义和示例.md)：八条公理、常见例子、反例与证明方法。
- [线性相关、基与维数](./线性相关、基与维数.md)：张成、线性相关与无关、基与维数，以及坐标表示。
- [线性映射与矩阵表示](./线性映射与矩阵表示.md)：核与像、秩–零化度定理，以及选基后的矩阵表示与换基相似。
- [函数空间是线性空间](./函数空间是线性空间.md)：以 $\mathbb F^X$ 为例逐条验证八条公理，并推广到 $C[a,b]$、$L^2[a,b]$ 与多项式空间。

核心关系：

$$
u+v\in V,
\quad
\lambdav\in V,
\qquad
T(\alphau+\betav)=\alpha T(u)+\beta T(v).
$$
