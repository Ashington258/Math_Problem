# 内积与正交化

本节研究“带几何结构的向量空间”：先引入双线性形式，再加上对称与正定得到内积，然后讨论正交化方法与三维中的叉积技巧。

- [双线性形式](./双线性形式.md)：双线性的一般结论、矩阵表示、非退化性与极化恒等式，以及张量积的泛性质。
- [叉积简化三维Gram-Schmidt正交化](./叉积简化三维Gram-Schmidt正交化.md)：用叉积代替 Gram–Schmidt，快速求实对称矩阵的正交特征向量。

核心关系：

$$
B(u,v)=u^{\mathsf T}Mv,
\qquad
(u,v)=0\iff u\perp v,
\qquad
\ker(A)=\operatorname{Row}(A)^{\perp}.
$$

本节是 [特征值与谱](../07_特征值与谱/README.md) 的前置：正交对角化需要一组标准正交特征向量基，而正交化的合法性来自内积的对称正定性。
